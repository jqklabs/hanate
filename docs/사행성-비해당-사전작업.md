## 0. 결론부터

**입증해야 할 명제는 세 개다.**

| # | 명제 | 현재 상태 |
|---|---|---|
| 1 | **재산상 이익·손실이 발생하지 않는다** (환전·현금구매·경품 없음) | ✅ 사실상 충족, ❌ **문서·고지로 증명된 바 없음** |
| 2 | **베팅·배당 구조가 아니다** (1인용, 상대·배당 없음) | ✅ 충족, ⚠️ **"내기"라는 용어가 정면으로 오해를 부름** |
| 3 | **우연이 아니라 기술로 결과가 결정된다** | ✅ 강력한 증거 보유(봇 승률 ~0%, 시드 재현), ❌ **정리된 형태로 없음** |

**핵심 진단:** 게임 자체는 이미 사행성이 아니다. 문제는 **입증 자료가 0개**라는 것. 코드 스캔 결과 판돈·베팅·도박·잭팟·당첨·환전은 **전부 0회** 등장하고 결제 코드도 **0줄**인데(구조적으로 매우 깨끗함), 정작 그 사실을 증명할 **약관·고지·연령표시·확률표시가 하나도 없다.** 심사에서 깨지는 건 게임이 아니라 서류다.

**가장 큰 단일 리스크:** 게임산업법 시행령이 사행성 판단 대상으로 **"화투를 모사한 게임물"을 명시적으로 열거**한다는 점. 즉 우리는 "왜 아닌지"를 **먼저 말해야 하는 쪽**이다. 심사관이 화투 도안을 보는 순간 입증 책임이 우리에게 온다는 전제로 준비해야 한다.

## 1. 무엇에 대해 입증하는가 (판단 기준 4갈래)

| 기준 | 요지 | 우리 해당 여부 |
|---|---|---|
| **게임산업법 사행성게임물 정의** | ① 베팅·배당을 내용으로 하고 ② 우연적 방법으로 결과가 정해지며 ③ 그 결과로 재산상 이익·손실이 발생 | ③이 없으므로 비해당. **③의 부재를 증명하는 것이 방어의 핵심** |
| **시행령상 모사 게임물 열거** | 화투·카드·슬롯머신·경마 등을 모사한 게임물을 사행성 판단 대상으로 열거 | **형식상 걸린다.** → 실질(환전·베팅 부재)로 반박해야 함 |
| **웹보드게임 규제** (월 결제한도·1회 베팅한도·상대선택 제한 등) | **유료로 구매한 게임머니**로 하는 고스톱/포커류에 적용 | **비해당** — 냥은 유료 구매 불가·환전 불가. 단 이 사실을 명시적으로 밝혀야 규제 대상 밖임이 확인됨 |
| **플랫폼 정책** | 구글 = 소셜카지노 사전 인증 필요 / 애플·구글플레이 = 도박 카테고리 심사 / Steam = 상대적으로 관대 | 광고는 인증 필요, 스토어는 연령 상향 가능성 가정 |

> 실무 감각: 국내 고스톱 게임들은 **사행성게임물로 분류되어 금지된 게 아니라**, 등급분류를 받고 (유료 재화가 있으면) 웹보드 규제를 적용받아 정상 유통된다. 우리 목표는 "게임을 통과시키는 것"이 아니라 **"웹보드 규제 대상도 아님"을 초기에 못박는 것**이다.

## 2. 방어 논리 3축과 증거

### 축 1 — 재산상 이익·손실 없음 (가장 결정적)

| 주장 | 증거 | 준비 상태 |
|---|---|---|
| 인게임 재화 "냥"은 현금으로 살 수 없다 | 결제 코드 부재 — `stripe/paypal/checkout/payment/IAP/toss` 검색 결과 **0건** | 사실이나 문서 없음 |
| 냥은 환전·양도·거래 불가 | 서버·계정 없음, 데이터는 세션 내에서만 존재 | 사실이나 문서 없음 |
| 경품·현물 보상 없음 | 대회·리워드 기능 없음 | 사실이나 문서 없음 |
| 게임 결과가 외부 가치와 연결되지 않는다 | 랭킹·리더보드·거래 기능 없음 | 사실이나 문서 없음 |

### 축 2 — 베팅·배당 구조 아님

| 주장 | 증거 | 비고 |
|---|---|---|
| 1인용 싱글플레이, 대전 상대 없음 | 코드 전체에 멀티플레이·매칭 없음 | 강함 |
| 배당률(odds)·페이아웃 테이블 없음 | 점수식은 `카드칩 × 족보배수` 결정론 | 강함 |
| "고"는 판돈 증액이 아니라 **목표 점수 상향** | `goThreshold(base,n)=ceil(base×(1+0.6n))` — 걸린 것은 재화가 아니라 진행 | **가장 설명이 필요한 지점** |
| 상점 특수패는 확률형 유료 아이템이 아님 | 유료 구매 경로 없음, 재화는 플레이로만 획득 | 강함 |

### 축 3 — 우연이 아니라 기술

| 주장 | 증거 | 비고 |
|---|---|---|
| 실력이 결과를 지배한다 | **그리디 봇 300런 승률 ~0%** — 단순 탐욕 알고리즘으로는 클리어 불가 = 판단이 결과를 만든다 | **가장 강력한 단일 증거.** `node test/test-game.mjs`로 제3자 재현 가능 |
| 난수가 조작되지 않는다 | 시드 고정(`?seed=42`) 시 완전 재현 | 투명성 증거 |
| 정보가 은닉되지 않는다 | 손패·목표·확률·족보 전부 공개, 프리뷰로 점수 사전 확인 | 슬롯머신류와의 결정적 차이 |
| 플레이어 선택이 매 턴 존재 | 1~5장 선택 · 버리기 · 고/스톱 · 상점 | 강함 |

## 3. 사전작업 체크리스트

### A. 코드 — 게임 내 (우선순위 순)

| # | 작업 | 왜 | 공수 |
|---|---|---|---|
| A1 | **"내기" 용어 재검토** — 게임 내 45회 등장, 버튼 라벨·튜토리얼·정산 화면 등 **사용자 노출 문자열 다수** | 심사관·이용자가 가장 먼저 보는 단어이자 유일한 오해 소지. 광고에선 이미 "기회 4번"으로 치환한 전례 있음. **대안 후보: 판(내는 횟수) / 패내기 / 手** — 게임성 손상 없이 바꿀 수 있는지 UX 판단 필요 | 중 |
| A2 | **"기본 상금" → "기본 정산" 등으로 변경** (정산 화면, 1곳) | 賞金은 경품·당첨 뉘앙스. 1줄 수정으로 제거 가능 | 소 |
| A3 | **하단 고지 1줄 상설 노출** — "본 게임은 실제 현금 베팅·환전·현물 보상이 없는 1인용 게임입니다" | 랜딩·게임 화면 양쪽. 광고 집행의 **선행 조건**이기도 함(캠페인 문서 미완료 항목) | 소 |
| A4 | **이용약관·개인정보처리방침 링크 추가** — 현재 **전무** | 환전 금지·계정 거래 금지 조항이 축 1의 핵심 증빙 | 중 |
| A5 | **연령 등급 표시 영역 확보** | 등급분류 후 표시 의무 발생. 자리를 미리 만들어둬야 재작업 없음 | 소 |
| A6 | **상점 티어 확률 게임 내 공개** (커먼 55 / 레어 28 / 에픽 13 / 레전더리 4%) | 현재 문서에만 존재. 유상 구매가 없어 확률표시 의무 대상은 아니지만, **자발적 공개는 "숨기지 않는다"의 직접 증거**로 심사에서 효과가 크다 | 소 |
| A7 | **저작권·문의 표기** | 심사 서류의 기본 요구 항목 | 소 |

> A1은 유일하게 **게임 디자인 판단이 필요한 항목**이다. "내기"는 고스톱 전통 용어이자 네이밍 방침(고스톱·한국 전통 용어)에 부합하는 단어라, 바꾸는 것이 정체성 손실일 수 있다. **권고: 게임 내 표기는 유지하되, 광고·스토어 설명·심사 서류에서는 전량 치환하고, A3 고지로 방어한다.** 심사에서 문제 제기가 실제로 오면 그때 교체한다 (교체 비용이 낮으므로 선제 교체는 과잉).

### B. 문서 — 증빙 패키지 (심사 제출용)

| # | 산출물 | 내용 | 용도 |
|---|---|---|---|
| B1 | **사행성 비해당 의견서 (1~2p)** | §2의 3축을 표로 정리 + 각 항목 증거 | GRAC·플랫폼·광고 심사에 **그대로 첨부**할 표준 문서. 가장 먼저 만들 것 |
| B2 | **게임 개요서** | 장르·루프·1인용·오프라인·수익모델 명시 | 등급분류 신청 첨부 |
| B3 | **재화(냥) 정책서** | 획득 경로(플레이 한정)·사용처(상점 한정)·소멸(런 종료)·**구매/환전/양도 전면 불가** | 축 1의 핵심 문서 |
| B4 | **실력 기반 게임 입증 자료** | 봇 300런 시뮬레이션 결과 + 재현 절차(`node test/test-game.mjs`) + 시드 재현 설명 | 축 3. **다른 게임은 못 내는 자료** — 최대 차별점 |
| B5 | **이용약관 초안** | 환전 금지, 계정·재화 거래 금지, 서비스 성격 | A4와 연동 |
| B6 | **용어 대응표** | 게임 내 표기 ↔ 대외(광고·스토어·심사) 표기 (내기→기회/판, 고→도전 등) | 카피 작성 시 실수 방지 |

### C. 외부 절차 (리드타임 있음 — 먼저 걸어둘 것)

| # | 절차 | 시점 | 비고 |
|---|---|---|---|
| C1 | **GRAC 사전 상담** | 유료 출시 결정 즉시 | "화투 소재 1인용, 유료재화 없음"으로 문의. **등급 예측과 웹보드 규제 비대상 확인**이 목적. 답변이 이후 전 작업의 기준선 |
| C2 | **구글 광고 소셜카지노 사전 인증 신청** | 광고 집행 4주 전 | 인증 없이는 게재 거부. A3 고지가 선행 조건 |
| C3 | **게임법 전문 법률 검토** | Steam 출시 전 | B1~B3을 들고 가면 검토 비용·시간이 크게 줄어든다 |
| C4 | **Steam AI 생성 콘텐츠 공시 준비** | 스토어 등록 시 | 춘향·배경 등 생성 에셋 목록화 |

### D. 증거 보존 (지금 해두면 나중에 공짜)

| # | 작업 | 비고 |
|---|---|---|
| D1 | 결제·서버 코드 부재 상태 **스냅샷 기록** | "구조적으로 환전이 불가능하다"를 커밋 해시로 증명 |
| D2 | 시뮬레이션 결과 로그 보존 | B4 근거. 밸런스 변경 시 재실행·재보존 |
| D3 | 사행성 관련 결정 이력 문서화 | 이 문서를 갱신 이력으로 유지 |

## 4. 절대 넘지 말아야 할 선 (설계 금지 목록)

이 선을 넘으면 위 논리가 **한 번에 전부 무너진다.** 기능 기획 시 상시 참조할 것.

| 금지 | 이유 |
|---|---|
| 냥의 **현금 구매** | 축 1 붕괴 → 즉시 웹보드게임 규제 대상(결제한도·베팅한도) |
| 냥·아이템의 **환전·양도·유저 간 거래** | 게임산업법 환전업 금지 조항 직결 |
| **현물·경품·상금** 지급 (이벤트 포함) | 경품 제공 제한 위반 소지 |
| **유료 확률형 아이템** (유료 상점 슬롯·유료 리롤) | 사행성 판단의 전형적 트리거 |
| **PvP 베팅·대전 매칭** | 축 2 붕괴 |
| **리더보드 + 현금 보상** 결합 | 결과가 재산상 이익과 연결됨 |
| 광고 리워드로 **런 되돌리기(부활)** | 정책 트리거 + 밸런스 철학 붕괴 (수익화 문서에서도 이미 비추천) |

> ⚠️ **문서 정리 필요:** 백로그에 **"뒤집기 찬스 — 도박성 이벤트"**(기획서 §11) / **"뒤집기 찬스(도박)"**(CLAUDE.md)라는 표현이 그대로 남아 있다. 기능 자체는 인게임 재화만 쓰므로 문제없지만, **우리 공식 문서가 스스로를 "도박성"이라 기술하는 상태**는 심사·소명 국면에서 최악의 자료다. 구현 여부와 무관하게 **지금 표현을 교체할 것** (예: "뒤집기 찬스 — 고위험 선택 이벤트"). 네이밍도 재검토 대상.

## 6. 한 줄 요약

게임은 이미 사행성이 아니다 — **결제 코드 0줄, 환전 경로 0개, 봇 승률 0%**가 그 증거다. 부족한 건 게임이 아니라 **그것을 말하는 서류**이고, 그중 절반은 오늘 공수 몇 시간으로 만들 수 있다.
