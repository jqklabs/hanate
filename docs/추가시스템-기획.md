# 화투로 — 한국식 추가 시스템 기획

> Balatro의 Joker / Enhanced Playing Cards / Spectral Cards를 그대로 복제하지 않고,
> 화투의 월·종류·고/스톱·박·냥을 중심으로 다시 설계한다.

## 0. 한 줄 요약

| Balatro 비유 | 화투로 명칭 | 역할 |
| --- | --- | --- |
| Joker | **특수패** | 최대 5개를 보유하는 지속형 아이템. 공통 득점·행동 훅으로 작동한다. |
| Enhanced Playing Card | **패단장** | 점괘를 사용해 무작위 후보 8장 중 선택한 화투패를 영구 가공한다. |
| Spectral Card | **춘향의 밑장** | 3·6·9월 박을 깨면 춘향이 내미는 강력한 비책 3택 1. 즉시 사용한다. |

세 시스템은 서로 다른 질문을 만든다.

- 특수패: **어떤 조건을 반복해 점수와 경제를 키울 것인가?**
- 패단장: **내 48장 중 어느 패를 주인공으로 만들 것인가?**
- 춘향의 밑장: **무엇을 희생하고 덱의 방향을 꺾을 것인가?**

현재 상점의 특수패 22종은 Balatro의 Joker와 같은 자리다. 별도 아이템 계층을
추가하지 않고 기존 슬롯·오퍼·리롤을 그대로 사용하며, 풀만 아래의 **특수패 40종**으로
확장한다. 현재 구현과 문서의 혼동을 막기 위해 실제 교체 전까지 README의
“특수패 22종” 표기는 유지한다.

## 1. 공통 설계 원칙

### 1.1 한국적인 것은 이름만이 아니다

효과도 한국 화투의 행동에서 출발한다.

- 월을 맞추고, 패를 남기고, 장수를 조절하고, 고를 밀친다.
- 광·열끗·띠·피의 서열과 낮/밤, 이달의 패, 박을 활용한다.
- “아무 조건 없이 +배수”보다 **플레이 순서·남기는 패·위험 감수**를 바꾼다.

### 1.2 세 시스템의 영역을 겹치지 않는다

| 시스템 | 지속 | 보관 | 주된 효과 |
| --- | --- | --- | --- |
| 특수패 | 런 동안 | 최대 5개 | 득점 조건, 보유패, 버리기, 고/스톱, 경제, 성장 |
| 패단장 | 해당 카드가 덱에 있는 동안 | 카드당 1개 | 개별 카드의 칩·월·보유·파손 특성 |
| 춘향의 밑장 | 선택 즉시 | 보관 불가 | 파괴·생성·복제·변환 같은 큰 덱 수술 |

### 1.3 점수 보정은 결과가 아니라 보상

특수패는 조건을 만족했을 때만 점수를 준다. 초반에는 단순 +점수·+배수로 버티고,
중반에는 특정 족보·남긴 패·장수 조건을 맞추며, 후반에는 성장형과 ×배수를 조합한다.
한 장마다 새 조작법을 만들지 않고 같은 공통 훅에서 조건과 수치만 바꾼다.

### 1.4 용어

- **발동**: 조건을 만족해 특수패 효과가 적용되는 순간
- **판당 1회**: 월이 바뀌면 다시 사용할 수 있음
- **소각**: 해당 런의 덱에서 영구 제거
- **생성**: 기본 48장에 없던 복제 패를 런 덱에 추가
- **강화**: 패단장 하나가 붙은 상태

## 2. 특수패 — Joker 대응

### 2.1 획득과 보유

- 기존 상점의 특수패 3개 제안, 리롤, 판매, 최대 5칸을 그대로 쓴다.
- 커먼 16 / 레어 13 / 에픽 8 / 전설 3, 총 40종.
- 같은 특수패는 한 런에 하나만 보유할 수 있다.
- 특수패의 누적값은 판매하면 사라진다.
- 내부적으로 진화·충전·자동 변환·소각·복제·효과 복사를 허용한다.
- 다만 플레이어는 기존의 내기·버리기·고/스톱·구매·판매만 한다. 특수패 전용 버튼,
  매 판 대상 선택, 순서 선택 모달, 되감기 화면은 만들지 않는다.
- 자동 대상은 최저 칩, 첫 발동, 가장 싼 특수패처럼 항상 결정적으로 고른다.

### 2.2 공통 발동 훅

| 훅 | 입력 | 허용 효과 |
| --- | --- | --- |
| `onScore` | 족보, 낸 장수, core, 서로 다른 월, 낮/밤, 박 | +점수, +배수, ×배수 |
| `onCardScored` | 낸 카드의 월·종류·태그와 `core/flat/effective` 구분 | 카드마다 +점수/+배수, 냥 |
| `onHeld` | 내기 뒤 손에 남은 카드 | 종류별 +점수/+배수 |
| `onDiscard` | 버린 장수·종류·순번 | 충전, 자동 강화, 덱 이동 |
| `onRoundStart/End` | 판, 남은 자원, 고 단계 | 판 단위 보상·초기화 |
| `onGo/Stop` | 선언, 고 단계, 정산 | 성장, 자동 공물, 보상 |
| `onBossLoss` | 박으로 실제 잃은 칩·막힌 행동 | 흡수, 저장, 다음 판 방출 |
| `onEnhance/Destroy` | 패단장 부여·덮어쓰기·옥장 파손·소각 | 자동 강화, 성장 |
| `onJokerTrigger/Destroy` | 다른 특수패 발동·판매·자동 파괴 | 충전, 효과 복사 |
| `onShop` | 판매·리롤·상점 퇴장 | 판매가 성장, 자동 희생 |

공통 자동 명령은 다음으로 제한한다.

| 명령 | 역할 | 자동 대상 규칙 예 |
| --- | --- | --- |
| `gain` | 점수·배수·냥 지급 | 발동한 카드/특수패 |
| `grow` / `decay` | 특수패 현재값 증감 | 자기 자신 |
| `charge` / `release` | 값을 저장했다가 조건에서 방출 | 마지막 내기, 다음 일반 판 |
| `setTarget` | 다음 족보·장수·월 목표 교체 | 고정 순환 또는 시드 RNG |
| `moveCard` / `maskCard` | 패를 자동 이동하거나 판정에서 잠시 감춤 | 첫 버리기·첫 내기의 최저 칩 |
| `enhanceCard` | 패단장 자동 부여 또는 카드 강화값 성장 | 최저 칩 미강화 패 |
| `transformCard` / `duplicateCard` | 카드 자동 변환·복제 | 조건을 만든 두 카드 중 최저 칩 |
| `destroyJoker` / `destroySelf` | 자동 희생·소진 | 가장 싼 다른 특수패 |
| `evolveJoker` | 조건 달성 시 이름·효과 진화 | 자기 자신 |
| `copyAbility` | 정해진 발동 하나를 재현 | 직전 발동한 비전설 효과 |

### 2.7 자동 발동 순서와 안전선

1. 판·내기 목표 갱신: `setTarget`, 진화 상태
2. 카드 자동 이동·감춤·변환
3. `onCardScored`와 `onHeld`
4. 고정 +점수 → +배수 → ×배수
5. 점수 확정과 경제 `pendingReward`
6. 충전·성장·감쇠
7. 카드 강화·변환·복제·소각과 특수패 자동 파괴
8. 진화와 다음 행동용 목표·메아리 저장

- 자동 효과는 프리뷰에 결과와 대상 카드를 먼저 표시한다.
- 경제·성장·RNG는 프리뷰에서 소비하지 않고 행동 확정 뒤 한 번만 처리한다.
- 자동 명령에는 `synthetic` 표식을 붙인다. 합성 명령은 `onEnhance`, `onDestroy`,
  `onJokerTrigger`를 다시 발생시키지 않아 연쇄 재귀를 막는다.
- `copyAbility`는 점수 효과만 한 번 복사하며 복사·경제·성장·파괴를 다시 복사하지 않는다.
- 자동 파괴·변환은 `cardKey`가 같으면 한 이벤트에 한 번만 처리한다.
- 품앗이는 자기 발동과 경제 전용 발동을 세지 않아 무한 충전을 막는다.
- 덱 20~64장 상한을 넘는 복제·소각은 명령과 그에 딸린 성장까지 함께 취소한다.
- 종류 변환 시 새 종류와 맞지 않는 고도리·단·비광 태그는 제거한다.
- 고 선언은 `goLevel` 확정 → `onGo` 1회 → 손패 보충 순으로 처리한다. “다음 내기”
  효과는 프리뷰에는 보이지만 실제 내기를 확정할 때만 한 번 소비한다.

| 효과군 | 해당 특수패 | 플레이어가 하는 일 | 자동으로 정하는 것 | 새 화면 |
| --- | --- | --- | --- | --- |
| 목표 추적 | 쪽집게, 윷가락, 새타령, 새벽종 | 평소처럼 내기 | 족보·장수·월 목표 | 없음 |

| 고/스톱 전환 | 복주머니, 고무신 거꾸로, 묵은 장맛, 고삐당기기, 판돈고사, 사기그릇 | 고/스톱 | 성장·개봉·공양·파손률 | 없음 |

요구하지 않는다. 자동 효과 때문에 새로 필요한 UI는 카드 본문의 현재값과 짧은 발동 연출뿐이다.

### 2.9 기존 시스템과의 자동 연결

- **점괘·패단장**: 복채는 점괘 소비를 성장으로 바꾸고, 칠장이는 이미 단장된 패를 키운다.
  도깨비방망이와 삼신할미는 약한 패를 자동 단장하며, 옥장 파손은 벼락맞은 대추나무를 키운다.
- **박**: 금줄은 실제 손실을 영구 성장으로, 비광우산은 다음 일반 판의 일시 점수로 바꾼다.
  같은 손실을 보더라도 장기 빌드와 즉시 복구 중 선택이 갈린다.
- **고**: 복주머니는 즉시 정산과 다음 내기 중 하나를, 묵은 장맛은 과거의 안전한
  스톱과 현재의 고를 연결한다. 고무신·고삐·사기그릇은 고 이후 점수와 위험을 바꾸고,
  판돈고사는 냥을 영구 성장으로 바꾼다. 별도 판돈 화면 없이 고 버튼 아래에 이번 선언으로
  변할 `복/장독/긴장/공양/파손률`을 한 줄로 미리 표시한다.
- **춘향의 밑장**: 소각 비책은 벼락맞은 대추나무, 패단장 비책은 복채·칠장이,
  덱 변형 비책은 팔도유람·연리지의 재료가 된다. 비책 선택 절차 자체는 늘리지 않는다.

### 2.10 공통 발동 연출

개별 미니 연출을 40개 만들지 않고 자동 명령별 짧은 연출을 공유한다.

| 명령 | 공통 연출 | 적용 예 |
| --- | --- | --- |
| `grow/decay` | 특수패 현재값이 위·아래로 한 칸 굴러가며 색이 변함 | 고도리꾼, 고무신 거꾸로 |
| `charge/release` | 카드 테두리에 작은 칸이 차고, 방출 때 저장값이 점수판으로 날아감 | 장독대, 비광우산 |
| `setTarget` | 본문 목표가 도장처럼 찍히며 교체됨 | 쪽집게, 새타령 |
| `moveCard/maskCard` | 대상 카드에 청색 잔상이 생겨 덱·손 방향으로 미끄러짐 | 밑장빼기, 도깨비감투 |
| `enhance/transform/duplicate` | 대상 카드 테두리를 한 번 두드린 뒤 새 무늬가 번짐 | 도깨비방망이, 연리지 |
| `destroy` | 대상이 재처럼 흩어지고 성장값이 특수패로 빨려 들어감 | 작두, 사기그릇 |
| `evolve/copyAbility` | 이름패가 뒤집히거나 직전 특수패의 색 파동이 한 번 메아리침 | 팔도유람, 만파식적 |

모든 연출은 0.6초 이내이며 여러 효과가 겹치면 명령 순서대로 빠르게 이어 붙인다.
`prefers-reduced-motion`에서는 이동 없이 현재값과 대상 테두리만 점멸한다.

## 3. 패단장 — Enhanced Playing Card 대응

### 3.1 점괘 소모품

Balatro에서는 강화 종류를 메뉴에서 골라 돈을 내는 것이 아니다. 상점·아르카나 팩에서
특정 강화가 적힌 Tarot를 얻고, 그 Tarot가 허용하는 수만큼 현재 손의 카드를 고친다.
화투로도 같은 제약을 다음처럼 번역한다.

1. 상점에 무작위 **점괘 2개**가 특수패와 함께 나온다.
2. 점괘마다 부여할 패단장과 선택 가능한 장수가 이미 정해져 있다.
3. 구매하면 런 덱에서 무작위 화투패 8장을 펼친다.
4. 그 8장 중 최대 1~2장을 골라 점괘의 단장을 붙인다.
5. 점괘는 즉시 사라지고 보관 슬롯은 만들지 않는다.

- 점괘는 특수패와 같은 리롤에 함께 바뀐다.
- 전체 덱에서 원하는 카드를 직접 고를 수 없다.
- 한 카드에는 패단장 하나만 붙고, 새 단장은 기존 단장을 덮어쓴다.
- 이미 단장된 카드도 후보에 나오며 덮어쓰기 전에 경고한다.
- 무작위 후보 8장은 점괘를 구매하는 순간 한 번만 정하고 다시 뽑지 않는다.
- 같은 단장은 덱의 여러 카드에 붙을 수 있다.
- 생성된 복제 패도 독립 `cardKey`를 받고 후보가 될 수 있다.

### 3.2 패단장 8종

| 점괘 | 가격 | 대상 | 붙는 단장과 효과 |
| --- | ---: | ---: | --- |
| **재물괘** | 4냥 | 최대 2장 | **금박** — 득점 시 카드 칩 +8 |
| **화기괘** | 4냥 | 최대 2장 | **홍칠** — core에 포함되면 족보 배수 +1 |
| **도깨비괘** | 5냥 | 최대 1장 | **도깨비무늬** — 본래 월과 현재 진행 월 중 족보가 높은 쪽으로 자동 둔갑 |
| **파옥괘** | 6냥 | 최대 1장 | **옥장** — core면 족보 배수 ×1.6. 1/4로 단장이 깨지고 그 월에 옥가루를 남김 |
| **철마괘** | 6냥 | 최대 1장 | **무쇠장** — 손에 남아 있으면 같은 월 core 카드 칩 ×1.5. 같은 월 여러 장은 중첩 없음 |
| **장승괘** | 5냥 | 최대 1장 | **장승패** — 종류·태그를 잃고 +25 flat. 병풍에서 빠진 월 하나를 대신 세울 수 있음 |
| **엽전괘** | 5냥 | 최대 1장 | **엽전장** — core 득점마다 엽전 1개(최대 2). 고하면 개당 다음 내기 +2배수, 스톱하면 개당 1냥 |
| **대길괘** | 5냥 | 최대 2장 | **복문** — 판 시작에 대길·길·흉 공개. 대길은 core +5배수, 길은 카드 칩 +10, 흉은 효과 없이 다음 판 대길 확정 |

금박·홍칠은 덱 강화 문법을 익히는 기본형으로 남긴다. 나머지 여섯 단장은 Balatro의
Wild·Glass·Steel·Stone·Gold·Lucky 대응을 끊고, 화투의 진행 월·병풍·같은 월·고/스톱·
공개 운세를 판단 재료로 사용한다.

화투로의 상점에는 “현재 손패”가 없으므로, 전체 덱 자유 선택 대신 무작위 8장을
임시 손패처럼 사용한다.
이 방식은 원하는 단장과 원하는 카드를 동시에 고르는 과도한 확정성을 막으면서도,
단장 효과를 구매 전에 알 수 있게 한다. Edition·Seal에 해당하는 두 번째·세 번째
수정자 층은 이번 기획에 넣지 않는다.

### 3.3 판정 우선순위

기본 카드 칩 순서는 기존 원칙을 보존한다.

1. 기본 칩
2. 이달의 패 ×2
3. 밤일낮장 +2
4. 금박 +8
5. 박 디버프 0

그 뒤 점수 계산에서:

1. 복문의 이번 판 운세를 읽는다. 프리뷰 중에는 다시 뽑지 않는다.
2. 도깨비무늬는 본래 월/진행 월, 장승패는 병풍의 빈 월 후보로만 대입한다.
3. `detectHandInfo`가 족보와 core를 함께 정한다.
4. 금박·복문 `길`의 카드 칩을 더한다.
5. 무쇠장이 받치는 같은 월 core 카드 칩에만 ×1.5를 적용한다.
6. 홍칠·복문 `대길`의 +배수, 옥장의 족보 배수 ×1.6을 적용한다.
7. 장승패 +25 flat과 나머지 flat을 더한다.
8. 최종 `Math.floor` 1회
9. 점수 확정 뒤 옥장 파손·옥가루·엽전 충전과 고/스톱 정산을 처리한다.

### 3.4 예외 규칙

- **국진**: 열끗/쌍피 전환과 패단장은 별개다. 전환해도 단장은 유지한다.
- **안개**: 뒷면이어도 단장 테두리는 감춘다. 공개되는 순간 함께 보인다.
- **도깨비무늬**: 종류·태그는 바꾸지 않는다. 본래 월과 현재 진행 월 두 후보만
  비교하며, 한 족보 안에서는 더 높은 점수의 한 월로 고정된다. 별도 월 선택 UI는 없다.
- **장승패**: 일반 족보의 core에는 들어가지 않는다. 병풍에서 정확히 한 달이 비었을 때
  장승패 하나가 그 자리를 메우되 core 칩은 0이고 +25 flat만 준다. 장승패 둘은 중첩하지 않는다.
- **옥장**: 파손되면 카드는 남고 단장만 사라진다. 깨진 월에는 옥가루 1개가 남으며,
  다음에 그 월 카드가 core가 되면 +6배수 후 사라진다. 월당 옥가루는 1개까지만 저장한다.
- **무쇠장**: 내기 확정 후 손에 남은 카드만 받침으로 센다. 같은 월 무쇠장 여러 장과
  여러 월 후보가 겹쳐도 해당 core 카드 칩에는 ×1.5를 한 번만 적용한다.
- **엽전장**: 엽전은 카드별 최대 2개이며 판을 넘어 보관된다. 고 선언에서는 냥 대신
  다음 내기 배수로, 스톱에서는 냥으로 자동 정산한다. 목표 실패·고박·런 종료에는 지급하지 않는다.
- **복문**: 판 시작 시 카드마다 운세를 한 번 뽑아 공개한다. `흉`은 페널티가 아니라
  이번 판 강화 효과가 없는 상태이며, 다음 판에는 RNG 없이 `대길`이 된다.

### 3.5 영구 카드 식별

현재 `uid`는 판마다 다시 만들어지므로 패단장 저장 키로 쓰면 안 된다.

- 기본 48장에는 `cardKey`를 부여한다. 예: `m03-pi-1`, `m08-godori`.
- 런 상태에는 `cardMods[cardKey] = { enhancement, nextFortune, coins }`를 저장한다.
- 옥가루는 `jadeDustByMonth[1..12]` 불리언으로 저장한다.
- 복문 운세는 판 상태의 `fortuneByCardKey`로 저장하고 판 종료 시 비운다.
- 생성 패는 `generated-<serial>` 키를 받는다.
- `tags[]`는 홍단·고도리·비광 같은 족보 전용으로 유지한다.
- 강화 데이터는 `enhancement` 필드로 분리한다.
- 매월 덱은 “기본 카드 목록 + 생성 - 소각”으로 재구성한 뒤 강화 정보를 입힌다.

## 4. 춘향의 밑장 — Spectral Cards 대응

### 4.1 등장 흐름

3·6·9월 박을 클리어하면:

1. 정산 결과를 확인한다.
2. 화면이 어두워지고 춘향이 밑장 세 장을 펼친다.
3. 비책 3개 중 하나를 고른다.
4. 필요한 카드·특수패를 직접 선택한다.
5. 효과를 즉시 적용하고 상점으로 간다.

비책은 보관·판매·리롤할 수 없고, 같은 런에 같은 비책이 다시 나오지 않는다.
춘향의 역할은 오직 **박을 깬 뒤 밑장을 내미는 사람**이다. 기존 예약·상시 훈수·호버
예측은 제거 대상이며 함께 부활시키지 않는다.

### 4.2 공통 문법

- 효과는 강하지만 반드시 희생, 무작위성, 다음 박 강화 중 하나를 포함한다.
- 선택하기 전 결과 후보와 대상 가능 여부를 보여 준다.
- 대상이 없어 사용할 수 없는 비책은 선택지에 나오지 않는다.
- “무작위 패”는 기본 48장의 카드 정의에서 뽑되, 생성 패이므로 중복 월·종류가 가능하다.
- 소각·생성은 다음 달뿐 아니라 남은 런 전체에 적용된다.

### 4.3 비책 10종

| 이름 | 효과 | 대가와 빌드 방향 |
| --- | --- | --- |
| **귀물부림** | 선택한 패 1장을 소각하고, 무작위 월의 강화된 피 3장을 생성한다. 각 패단장은 금박·엽전장·복문 중 무작위. | 덱이 2장 늘어난다. 피5·경제 빌드용. |
| **광명부** | 선택한 패 2장을 소각하고, 서로 다른 월의 광 1장과 열끗 1장을 생성한다. 둘 중 하나에 옥장. | 총 장수는 같지만 옥장 파손 위험. 광·멍 빌드 전환. |
| **사방주문** | 선택한 패 1장을 소각하고, 서로 다른 월의 띠 또는 피 4장을 생성한다. 생성 종류는 하나를 고른다. | 덱이 3장 두꺼워진다. 단·피5 재료를 대량 확보. |
| **환골탈태** | 같은 종류의 패를 최대 3장 고른다. 종류는 유지한 채 월을 각각 다시 뽑는다. 한 장에는 도깨비무늬가 붙는다. | 완성 직전 족보가 깨질 수도 있다. 월 분포 재편. |
| **혼례상** | 패 두 장을 고른다. 한 장을 소각하고 다른 한 장을 복제한다. 복제품과 원본에 같은 무작위 패단장을 붙인다. | 다양성을 버리고 한 월·종류에 집중. |
| **살풀이** | 패 3장을 소각한다. 다음 박까지 기본 목표 +15%. 대신 패단장 3개를 보고 원하는 카드 3장에 무료 적용한다. | 강한 덱 압축과 강화 대신 한 구간 난도 상승. |
| **바꿔치기** | 금박·홍칠·엽전장이 붙은 강화 패 중 2장을 골라 패단장을 서로 바꾼다. 그 뒤 하나를 금박→홍칠, 홍칠→옥장, 엽전장→복문 중 해당 경로로 올린다. | 적용 가능한 단장을 명확히 제한하고 원하는 카드에 강화를 몰아준다. |
| **업보장부** | 보유 특수패 1개를 없애고 한 단계 높은 희귀도의 특수패 3개 중 하나를 얻는다. 전설을 바칠 수 없다. | 완성된 시너지를 깨고 더 높은 천장에 도전. |
| **달집태우기** | 월 하나를 고른다. 그 달의 기본 4장을 모두 소각하고, 다른 한 월의 기본 4장을 복제한다. | 총 장수 유지. 총통·폭탄은 쉬워지나 월 다양성·병풍은 약화. |
| **저승문** | 덱에서 가장 낮은 기본 칩 패 5장을 소각한다. 이후 모든 박의 목표 +20%. | 극단적 덱 압축. 3월에 잡으면 긴 고통, 9월에는 강한 막판 승부수. |

### 4.4 월별 가치 보정

보상을 받은 뒤 남은 판은 3월 9판, 6월 6판, 9월 3판이다. 동일한 지속 효과를 그대로
주면 3월 보상이 압도적으로 강해진다.

- 3월: 즉시 덱 수술 중심. 무료 냥·영구 수치 보너스는 낮춘다.
- 6월: 생성 패 하나에 패단장을 추가로 붙일 수 있다.
- 9월: 선택 후 `행운 한 번`을 제공해 무작위 결과를 한 차례 다시 뽑을 수 있다.
- 핵심 비책 10종은 모두 3월부터 나올 수 있다. 후반 전용 콘텐츠는 만들지 않는다.

### 4.5 12월 처리

12월 박을 깬 뒤에는 사용할 판이 없다. 성장 비책 3택 1은 의미가 없으므로 지급하지
않는다. 대신 확장 단계에서 **마지막 밑장**을 승리 결산으로 사용한다.

- `대길`: 최종 점수 기록 강조
- `대박`: 최종 보유 냥 기록 강조
- `명인`: 완성한 특수패·패단장 도감 강조

이는 런 파워나 영구 해금이 아니라 엔딩 문구와 기록 분류만 바꾼다.

## 5. 상점과 한 해의 새 흐름

```text
일반 월 클리어
→ 정산
→ 상점: 특수패 3개 + 점괘 2개
→ 점괘 구매 시 무작위 패 8장 중 1~2장 강화
→ 다음 달

3·6·9월 박 클리어
→ 정산
→ 춘향의 밑장 3택 1
→ 상점: 특수패 3개 + 점괘 2개
→ 다음 계절

12월 박 클리어
→ 승리
→ 마지막 밑장(확장: 결산 분류)
```

### 상점 화면 원칙

- 특수패와 점괘는 같은 상점 리롤에 포함하되 섹션을 구분한다.
- 특수패는 지속 아이템, 점괘는 구매 즉시 사라지는 카드 강화임을 표시한다.
- 점괘 카드에는 단장 효과와 `최대 1장` 또는 `최대 2장`을 표시한다.
- 점괘 구매 후에는 전체 덱 대신 무작위 후보 8장만 펼친다.
- 덱 보기에서 패단장별 필터와 소각·생성 카드 수를 보여 준다.

## 6. 밸런스 가드레일

### 6.1 기존 난도 철학 유지

- 새 시스템 도입 후에도 무강화·무특수패 런은 3월 벽이 유지되어야 한다.
- 시스템 추가를 이유로 목표 점수를 낮추지 않는다.
- 플레이어 파워가 크게 오르면 4월 이후 목표 또는 박 목표를 올린다.
- 특수패·패단장·밑장을 모두 쓰는 봇의 12월 승률도 초기에는 낮게 유지한다.
- 현행 경제는 정산·고 보상으로 후반 냥이 남기 쉬우므로, 점괘는 새 **지속 소모처**로
  기능해야 한다. 광팔이·상평통보·복주머니·엽전장의 총 기대 수입보다
  특수패·점괘 구매와 리롤의 총 기대 지출이 낮아지지 않게 조정한다.

### 6.2 수치 예산

| 항목 | 권장 예산 |
| --- | --- |
| 커먼 특수패 | 한 번 발동 +15~30점, +2~5배수 또는 판당 1~3냥 |
| 레어 특수패 | 3~5회 준비 뒤 +8~12배수·×2, 또는 판당 ×0.1 이하 성장 |
| 에픽 특수패 | 덱 변형·파괴 대가를 포함한 ×1.75~2.5 또는 다음 판 점수 이월 |
| 전설 특수패 | 6판 이상 완성하는 진화·자동 강화·제한된 점수 효과 복사 |
| 패단장 | 카드 한 장 기준 평균 점수 10~25% 상승 |
| 춘향의 밑장 | 에픽 특수패 1개보다 강하지만 되돌릴 수 없는 대가 포함 |

### 6.3 금지 조합과 상한

- 옥장은 족보 배수, 무쇠장은 같은 월 core 카드 칩만 높이며 flat은 증폭하지 않는다.
- 무쇠장은 조건을 만족하는 카드마다 ×1.5를 한 번만 적용하고 여러 장이 중첩되지 않는다.
- 옥가루는 월당 1개, 발동 시 +6배수 한 번으로 제한한다.
- 복문 운세는 카드별로 판당 한 번만 정하며 대길 확정은 다음 판을 넘겨 이월하지 않는다.
- 엽전장 정산은 판당 최대 4냥.
- 광팔이는 판당 최대 2냥, 피장사는 보따리 5개당 2냥으로 고정한다.
- 칠점은 카드당 +10점, 고도리꾼은 ×3, 판돈고사는 ×3에서 우선 소프트캡을 검토한다.
- 고삐당기기는 긴장 4개(×1.8), 묵은 장맛은 장독 3개(×1.9)를 넘지 않는다.
- 밀치기로 고 단계가 여러 칸 뛰어도 `onGo`는 선언 1회로만 발동한다.
- 사기그릇은 고 1회당 현재 저장점의 50%만 한 번 더하고 파손률은 최대 1/2이다.
  프리뷰 점수를 다시 저장하지 않으며 방출 점수는 다른 충전 효과의 입력이 아니다.
- 팔도유람은 구매 전 `stats.scoredMonths`를 소급해 늦게 얻어도 죽은 전설이 되지 않게 한다.
- 저승문으로 덱이 20장 미만이 되면 선택할 수 없다.
- 생성 패 포함 덱 최대 64장, 소각 후 최소 20장.

### 6.4 프리뷰 원칙

- 확정 점수: 금박, 홍칠, 무쇠장처럼 결과가 정해진 효과는 반영한다.
- 공개 운세: 복문은 카드에 `대길/길/흉`을 표시하고 현재 상태의 확정 점수를 반영한다.
- 확률 결과: 옥장은 성공 점수, 1/4 파손 확률, 파손 시 남길 옥가루 월을 함께 표시한다.
- 경제 효과: 예상 냥만 보여 주고 실제 지급은 확정 행동에서만 한다.
- 사기그릇은 현재 저장점·고 선언 뒤 파손 확률·파손 시 총점을 함께 표시한다.
- 자동 변환·귀환은 프리뷰 카드에 `감춤`, `귀환`, `칠 +N`처럼 결과 배지를 붙인다.
- 쪽집게의 예언은 현재 손에서 실제로 만들 수 있는 족보 중 시드 RNG로 정한다.
- 동률 자동 대상은 기본 칩이 낮은 순서 → `cardKey` 오름차순으로 정해 시드와 무관하게 같다.
- 작두의 동가 특수패는 카탈로그 `id` 오름차순으로 정해 보유 칸 순서에 의존하지 않는다.

## 7. 구현을 위한 데이터 경계

이번 문서는 기획만 다루지만, 이후 구현에서 아래 경계를 지켜야 한다.

### 엔진

- `buildDeck()`은 기본 카드 정의를 만들고 런 덱 상태를 적용한다.
- `detectHandInfo()`가 족보와 core를 계속 한 번에 결정한다.
- `cardChip()`에 패단장 순서를 명시적으로 넣는다.
- `computeScore()`는 프리뷰와 실제 점수 계산이 공유한다.
- 엔진 마커 내부에는 DOM이나 경제 지급을 넣지 않는다.
- `resolveSpecialCards(event, snapshot)`은 순수 함수로 점수 보정, 상태 변경 명령,
  `pendingReward`, 연출용 발동 기록만 반환한다.
- 프리뷰는 누적값·냥·RNG를 소비하지 않고 확정 행동에서 반환 명령을 한 번만 적용한다.

### 런 상태

```text
runDeck:
  baseCards
  generatedCards
  removedCardKeys
  cardMods
  cardTransforms
  jadeDustByMonth

roundEnhancement:
  fortuneByCardKey

jokers:
  owned[]:
    id
    paid
    data
    currentValue
    target
    charges
    evolvedFrom

runStats:
  scoredMonths[]
  handStamps{}
  destroyedCardKeys[]
  lastTriggeredJokerId

chunhyangReward:
  offers[]
  offeredIds[]
  selectedId
```

`uid`는 현재 손패 선택에만 쓴다. 영구 강화·소각·생성은 `cardKey`로 추적한다.
`cardTransforms`는 환골탈태처럼 원본 카드의 월·종류가 바뀐 결과를 저장하고,
`offeredIds`는 선택 여부와 관계없이 이미 제시된 비책의 재등장을 막는다.
특수패 `data`에는 숫자뿐 아니라 월 도감, 족보별 도장, 다음 목표처럼 효과를 설명하는
작은 직렬화 상태를 둘 수 있다. 렌더링은 이 상태를 읽기만 하며 자동 대상 결정은 엔진이 한다.

## 8. 단계별 도입

### 1단계 — 특수패 공통 훅

- 기존 `addChips/addMult/xMult`를 `onScore/onCardScored/onHeld` 문법으로 정리
- `onDiscard`, `onGo/Stop`, `onRoundEnd`, `onShop`, `onBossLoss`,
  `onEnhance/Destroy`, `onJokerTrigger/Destroy` 확정 훅 추가
- `gain/grow/charge/release/setTarget`와 자동 대상 결정기를 먼저 구현
- 커먼 16종부터 적용하고 상점·판매·리롤·5칸은 유지
- 별도 사용자 조작과 좌우 재배치는 구현하지 않음

### 2단계 — 특수패 40종

- 레어 13 / 에픽 8 / 전설 3 추가
- `moveCard/enhanceCard/transformCard/destroyJoker/evolveJoker/copyAbility` 추가
- 장독대·쪽집게·팔도유람처럼 현재값·다음 목표가 바뀌는 카드의 공통 상태 UI
- 카드 자동 변환은 최저 칩→`cardKey`→현재 손의 `uid` 순으로 동률을 해소
- 만파식적 복사는 점수 명령만 허용하고 복사·경제·파괴 명령은 차단
- 특수패 조건을 이해하는 상점 봇과 300런 재시뮬레이션

### 3단계 — 점괘·패단장 MVP

- `cardKey`, 런 덱, 점괘 2개 상점 슬롯
- 구매 후 무작위 카드 8장 선택 모달
- 금박·홍칠·도깨비무늬·옥장·무쇠장·장승패·엽전장·복문 8종
- 덱 보기 필터와 카드 테두리

### 4단계 — 춘향의 밑장 MVP

- 3·6·9월 박 정산 뒤 화면 추가
- 춘향 레거시 훈수 제거
- 귀물부림, 광명부, 환골탈태, 혼례상, 살풀이, 업보장부 6종
- 대상 없음 필터, 같은 런 중복 방지

### 5단계 — 전체 확장

- 비책 10종 전체
- 강화패 보따리(Standard Pack 대응) 도입 여부 검토
- 12월 마지막 밑장 결산
- 모바일 선택 UI와 전용 연출
- 사람 플레이 로그를 통한 가격·목표 재조정
- 각 단계는 기본 300런 회귀 시뮬레이션을 통과한 뒤, 최종 수치 확정 시 600런으로
  재검증해 3월 벽·6~7월 도달률·냥 잔액 분포를 함께 확인

## 9. 성공 기준

새 시스템이 성공한 상태는 단순히 점수가 커진 상태가 아니다.

1. 상점에서 당장 강한 특수패와 성장 가능한 특수패 사이를 고민한다.
2. 같은 광이라도 금박 광, 옥장 광, 엽전장 광의 쓰임이 달라진다.
3. 박을 깬 뒤 춘향의 세 밑장이 다음 세 달의 빌드 방향을 바꾼다.
4. 덱을 얇게 만들수록 좋은 효과와 월 다양성을 잃는 위험이 함께 커진다.
5. 장독대·고무신 거꾸로·도깨비감투처럼 이름을 들으면 발동 장면이 떠오른다.
6. 종류가 40종으로 늘어도 새 조작법 대신 현재값과 다음 조건만 읽으면 이해된다.

이 여섯 가지가 체감되지 않으면 수치가 아니라 효과 구조를 먼저 다시 설계한다.
