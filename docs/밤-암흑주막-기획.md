# 밤 · 암흑 주막

> 동기: 2~5월 냥 수급이 말이 안된다. 고등급은 **고를 밀어 밤을 선택한 사람에게 이점을 줌.**

## 한 줄 요약

낮 판에서 3고 이상하고 스톱하면 "**밤"**에 도전할 수 있다. 밤을 깨고 스톱하면 "암흑 등급" 아이템이 등장하는 "**암흑 주막"**이 열린다.

## 삭제

현행 **낮/밤 기본 칩**은 없앤다.

- 홀수 달 낮: 광·열끗 +2
- 짝수 달 밤: 띠·피·쌍피 +2

이달의 패(해당 월 카드 칩 ×2)는 그대로 둔다.

## 흐름

2월부터 같은 달 낮을 깬 뒤에만 밤을 고른다. (1월에는 밤이 없다.)

```
1월 낮 → 주막
2월 낮 → (3고+ 스톱) → 밤 도전? 
           ├ 거절 → 주막
           └ 수락 → 2월 밤 → 스톱 성공 → 암흑 주막
3월 낮 → …
```

낮에서 2고 이하로 스톱하면 팝업 없이 바로 주막으로 간다.

밤에서 고박하면 런이 끝난다. (낮에서 이미 넘긴 달을 되돌리지는 않는다.)

## 밤 도전 팝업

낮 판에서 **3고 이상**을 선언한 뒤 스톱하면 묻는다.

- 거절: 정산 후 평소 주막
- 수락: 같은 달 **밤 판**을 바로 시작한다

문구 초안: **밤에 도전하시겠습니까?**

## 밤 판 규칙

낮과 같은 달이되, 목표와 정산만 배로 키운다.


| 항목       | 낮                        | 밤                                |
| -------- | ------------------------ | -------------------------------- |
| 기본 목표    | 그달 커브 그대로 (`TARGETS[월]`) | **그달 기본 목표 ×2**                  |
| 고 문턱     | `ceil(기본 × (1+0.6n))`    | **기본이 이미 ×2**라 문턱도 전부 ×2         |
| 정산 냥     | 그대로                      | **전부 ×2** (이자·기본·남은 내기·고 보너스·보험) |
| 내기 / 버리기 | 4 / 4                    | 4 / 4 (새로 시작)                    |
| 슬롯       | 그달 칸                     | 그달 칸 (2월 밤은 2칸)                  |


고를 칠 때마다 다음 목표가 낮보다 두 배로 벌어진다. 기본 목표를 두 배로 두는 것으로 처리한다. 고 계수(0.6)를 다시 두 배로 곱하지는 않는다.

밤도 고는 무제한이다. 밤에서 3고를 또 칠 필요는 없다. 스톱만 하면 암흑 주막으로 간다.

## 암흑 주막

밤을 스톱으로 끝낸 뒤에만 등장한다. (칸·리롤·판매는 평소 주막과 같다.)

다른 점은 딱 두 가지.

1. **등급 확률**은 `{현재 월 + 2}`월 주막 확률을 사용한다. (월별 주막 아이템 등급 등장 확률 14월 까지 만들어둬야겠지)
  예: 2월 밤 → 4월 주막, 5월 밤 → 7월 주막. 12월을 넘으면 14월 표.
2. **암흑** 등급은 `{이번 밤에서 친 고*2 + 1}%` 확률로 등장
  예: 밤 3고 → 6%, 밤 5고 → 8%.

암흑 특수패는 암흑 주막에서만 나온다. 평소(낮) 주막·리롤에는 안뜸.

## 암흑 등급

커먼 / 레어 / 에픽 / 레전더리와 별개인 **다섯 번째 등급**.  
하이리스크 하이리턴 전용 아이템으로 슬롯은 기존 특수패와 공유합니다.
