## 0. 결론부터

| 항목 | 결정 |
|---|---|
| **1순위** | **Steam 유료 출시** ($4.99~6.99). 웹판은 영구 무료 데모 겸 퍼널로 유지 |
| **2순위** | itch.io 유료/기부형 동시 게시 (검증 비용 0, 즉시 가능) |
| **하지 말 것 (당분간)** | 웹 인게임 광고, 웹 IAP(부활권·리롤권), 모바일 스토어 선출시 |

| **선결 조건** | 저장/불러오기(현재 미구현), 데스크톱 래핑, 콘텐츠 볼륨(추가시스템 3종) — §5 |

## 1. 지금 자산으로 팔 수 있는 것 / 없는 것

### 팔 수 있는 것 (강점)

| 자산 | 수익화에서의 의미 |
|---|---|
| 완성된 코어 루프 (12판·족보 13·특수패 22·박·고/스톱) | 이미 "게임"이다. 프로토타입이 아니라 상품 후보 |
| 마찰 0 (설치·로그인·서버 없음) | 데모 전환율이 극단적으로 높은 구조. **무료 웹판 = 최고의 데모** |
| 문화적 고유성 (화투 48장·계절·춘향) | 글로벌 스토어에서 "또 하나의 발라트로 클론"과 구분되는 유일한 축 |
| 난이도 서사 (봇 300런 승률 ~0%) | 하드코어 덱빌더 커뮤니티에 그대로 먹히는 마케팅 훅 |
| 텔레메트리 (GA4 + Firestore 원본) | 유료화 판단을 **감이 아니라 데이터로** 할 수 있음 |

### 팔 수 없는 것 (현 시점의 구조적 공백)

| 공백 | 수익화 영향 |
|---|---|
| **저장/불러오기 없음** (로드맵 "후보"에만 있음) | 한 런 = 12판. 중간 저장이 없으면 유료 구매자가 첫 환불 사유로 삼는다. **유료 출시의 하드 블로커** |
| 계정·서버 없음 (localStorage만) | 웹에서 무언가를 판매하면 "결제했는데 브라우저 지우니 사라짐" 문제 직행 |
| 메타 진행(언락·도전과제) 없음 | 로그라이크 유료판의 리텐션 축이 통째로 비어 있음 |
| 콘텐츠 볼륨 | 특수패 22종·족보 13종. 유료 기준선은 통상 조커 100+ 급. 추가시스템 기획(특수패 40종·패단장 8종·비책 10종)이 정확히 이 구멍을 메운다 |
| 오디오·폴리시 상태 | `Assets/SFX` 존재하나 유료 기대치 대비 점검 필요 |

## 2. 옵션별 평가

평가 축: 예상 수익 / 필요 공수 / 정책·법적 리스크 / 게임 훼손도

### A. Steam 유료 출시 — **★ 추천**

- **구조**: 웹판 무료 유지(데모) → Steam 유료판(저장·메타진행·추가시스템·도전과제·클라우드 세이브·컨트롤러).
- **가격대**: $4.99~6.99 (한국 6,500~9,500원). 인디 덱빌더 하한대이면서 "한 번 사고 끝"의 심리적 문턱 아래.
- **수익 구조**: Steam 수수료 30%, 등록비 $100(매출 $1,000 도달 시 환급).
- **공수**: 단일 HTML → **Tauri 래핑**이면 실질 며칠. 진짜 공수는 게임이 아니라 **저장 시스템 + 콘텐츠 볼륨 + 스토어 에셋(트레일러·스크린샷)**. 캠페인 영상 작업(`design/14_campaign_video`)이 트레일러 자산으로 그대로 재활용된다.
- **리스크**: 낮음. Steam은 화투 테마를 소셜 카지노로 분류하지 않는다(현금 베팅·현금 상금 없음). 국내 유통 시 GRAC 등급분류 이슈는 §4 참고.
- **훼손도**: 0. 게임 디자인을 수익화에 맞춰 비틀 필요가 전혀 없다 — **이 항목이 결정적이다.**

### B. itch.io 게시 (유료 or "원하는 만큼 지불") — **★ 즉시 실행**

- 오늘 당장 가능. 수수료 자유 설정(기본 10%), 심사 없음.
- 수익 자체는 작다(월 수만~수십만 원 수준을 기대). **가치는 수요 검증**: "무료로 하던 사람 중 몇 %가 돈을 내는가"를 Steam 투자 결정 전에 실측한다.
- 웹 빌드 그대로 업로드 가능(단일 HTML) → 공수 반나절.

### C. 웹 인게임 광고 (AdSense/H5 네트워크·리워드 광고) — **비추천**

- 리워드 광고를 붙일 자리는 명백하다(고박 후 부활, 상점 리롤 1회, 춘향 훈수). 그런데 그 자리들이 **전부 이 게임의 긴장 설계 핵심**이다. 고박이 런 종료라서 고가 무섭고, 리롤이 유한해서 상점이 선택이다. 광고로 되돌릴 수 있는 순간 밸런스 철학("빡빡하게, 하향보다 상향")이 붕괴한다.
- 경제성: 한국 웹게임 디스플레이 CPM은 낮고, 회수하려면 대규모 DAU가 전제다. 현재 유입 규모에서 광고 수익은 커피값 수준이면서 리텐션은 확실히 깎는다.
- 정책: 화투 + 광고 = 소셜 카지노 심사 트리거. 구글 캠페인 문서에서 이미 확인된 리스크(사전 인증 필요)와 같은 계열.

### D. 웹 결제 IAP (Stripe/토스페이먼츠) — **비추천 (현 단계)**

- 계정 시스템 + 서버 + 환불/청약철회 처리 = 게임 개발과 무관한 인프라 공수가 게임 공수를 초과한다.
- 소액결제 특성상 PG 수수료 비중이 크고, 무로그인이라는 최대 강점을 스스로 파괴한다.
- 예외: **"후원" 단방향 버튼**(Buy Me a Coffee / 토스 송금 링크)은 공수 0이므로 지금 붙여도 무방. 기대 수익은 낮지만 마이너스가 없다.

### E. 모바일 스토어 (Google Play / App Store) — **후순위**

- 화투·고스톱은 스토어에서 **카지노/도박 카테고리 심사**를 직격으로 받는다. 현금 베팅이 없어도 "내기 4회", "판돈" 류 용어가 심사 리스크다(광고 문서에서 이미 "기회 4번"으로 치환한 전례).
- 국내 출시 시 **GRAC 등급분류 필수**, 자체등급분류 사업자 경유 가능하나 화투 소재는 청소년이용불가 판정 가능성을 사전에 가정해야 한다.
- 조작은 이미 터치 친화적(카드 선택 기반)이라 이식 자체는 어렵지 않다. **Steam 성과가 나온 뒤에 볼 것.**

### F. 웹게임 퍼블리셔 수익쉐어 (Poki / CrazyGames) — **조건부**

- 트래픽을 그쪽이 대주고 광고 수익을 쉐어하는 구조. 단일 HTML이라 기술 적합도는 매우 높다.
- 단, 이들 플랫폼의 주 이용층은 저연령·짧은 세션이고 우리 게임은 한 런 20~40분급 하드코어다. **핏이 나쁘다.** 화투 소재 심사도 별건.

### G. 라이선싱·B2B·굿즈 — **기회형**

- 전통문화 콘텐츠(한국콘텐츠진흥원·지자체 문화사업), 전시/체험 전용 빌드, 화투 굿즈. 능동적으로 추진할 성질은 아니고 **인바운드가 오면 받는** 트랙.

## 3. 권장 로드맵

### Phase 0 — 검증 (지금~4주, 추가 개발 최소)

1. **itch.io 게시** (유료 $3 또는 pay-what-you-want) + 웹판에 후원 링크 1개.
2. **Steam 스토어 페이지 선공개** → 위시리스트 수집 시작. (등록비 $100 외 비용 없음)
3. 현재 GA4/Firestore로 **수익화 판단 지표** 확정 측정 — §6.
4. 판단 기준: 위시리스트 증가 속도와 D7 리텐션이 §6 게이트를 넘으면 Phase 1 착수.

### Phase 1 — Steam 유료판 (Phase 0 통과 시)

| 작업 | 성격 |
|---|---|
| **저장/불러오기** | 하드 블로커. 런 중단·재개 |
| **메타 진행** (해금·도전과제·통계) | 유료 리텐션 축 |
| **콘텐츠 볼륨 확장** | 추가시스템 기획(특수패 40종·패단장 8종·춘향 비책 10종) 구현 |
| Tauri 데스크톱 래핑 | Win/Mac 빌드, Steamworks 연동(도전과제·클라우드) |
| 스토어 에셋 | 트레일러(캠페인 영상 자산 재활용)·스크린샷·카피(캠페인 copy.md 재활용) |
| 로컬라이제이션 | 영문 필수. 화투 족보 용어 번역이 진짜 난제 — 글로벌 매출의 대부분이 여기 달림 |

> **웹판은 계속 무료.** 유료판과의 차이는 "게임의 일부를 잠그는 것"이 아니라 **저장·메타진행·볼륨**이다. 무료판을 훼손해 유료를 파는 방식은 지금의 최대 강점(마찰 0 유입)을 죽인다.

### Phase 2 — 확장 (Steam 검증 후)

모바일 이식(GRAC 등급분류 선행) · 추가 콘텐츠 DLC 또는 무료 업데이트 · 언어 확장.

## 4. 법적·정책 리스크 점검

| 항목 | 판단 | 조치 |
|---|---|---|
| **사행성 여부** (게임산업법) | 현금 베팅·현금/현물 환전이 **없으므로 사행성게임물 아님**. 게임 내 "냥"은 환전 불가 인게임 재화 | 유료화 이후에도 **냥의 현금 구매·환전은 절대 도입 금지**. 이 선을 넘는 순간 규제 범주가 바뀐다 |
| **GRAC 등급분류** | 국내 유통 유료 게임은 등급분류 대상. 화투 소재는 심의 시 연령 상향 가능성 | 스토어 출시 전 자체등급분류 사업자(스토어) 경유 또는 GRAC 직접 신청. 화투 소재 사전 문의 권장 |
| **광고 플랫폼 소셜 카지노 정책** | 구글은 사전 인증 필요(캠페인 문서 §4에서 확인됨) | 랜딩 고지 "현금 베팅·상금 없음" 1줄 — **미완료 상태, 광고 집행 전 필수** |
| **상표** | "발라트로"는 타사 상표 | 스토어 설명·태그에 직접 사용 금지. "로그라이크 덱빌딩"으로 우회(기존 방침 유지) |
| **화투 도안 저작권** | 공용 디자인, 문제 없음 | — |
| **폰트 라이선스** | `Assets/Fonts` — **상용 배포 라이선스 미확인** | 유료 출시 전 전 폰트 라이선스 실사 필수 (임베딩·상용 배포 허용 여부) |
| **AI 생성 에셋** | 춘향 캐릭터·배경 등 생성 에셋 존재 | Steam은 AI 생성 콘텐츠 **공시 의무**. 스토어 등록 시 신고란 정확히 기재 |
| **결제 시** | 전자상거래법·청약철회 | Steam/itch 경유 시 플랫폼이 처리 → 자체 결제를 피해야 할 또 하나의 이유 |

## 5. 유료화 선결 조건 (블로커 순)

1. **저장/불러오기** — 없으면 유료 판매 자체가 성립하지 않는다. 현재 로드맵상 "후보"로만 있음 → **최우선 승격 권고**.
2. **콘텐츠 볼륨** — 추가시스템 기획 3종 구현. 유료 기대치의 하한선.
3. **폰트 라이선스 실사** — 법적 블로커. 확인 전 배포 불가.
4. **데스크톱 빌드 파이프라인** — Tauri 래핑 + Steamworks.
5. **영문 로컬라이제이션** — 매출 규모를 결정하는 변수. 국내만으로는 유료 인디 시장이 좁다.

## 6. 판단 지표 (현 텔레메트리로 즉시 측정 가능)

Phase 1 착수 여부를 아래 게이트로 결정한다. 임계값은 인디 덱빌더 통념 기반 **제안치**이며, 실측 2주 후 재조정 대상.

| 지표 | 산출 | 게이트(제안) | 의미 |
|---|---|---|---|
| D7 리텐션 | GA4 Retention (`hwatro_uid`) | ≥ 10% | 유료로 붙잡을 유저가 존재하는가 |
| 세션당 평균 플레이 시간 | `session_end.session_play_sec` | ≥ 15분 | 하드코어 핏 확인 |
| 유저당 런 수 | `run_end` 카운트 / uid | ≥ 3 | 재도전 욕구 = 로그라이크 성립 |
| 도달 월 분포 | `run_end.month` | 6월 이상 비율 ≥ 20% | 난이도 벽이 이탈이 아닌 동기가 되는가 |
| 승리율 | `run_end.won` | 1~5% | 0%면 좌절, 10%+면 싱겁다 |
| itch 전환율 | 결제 / 웹 유니크 | ≥ 0.5% | **가장 직접적인 지불 의사 신호** |
| Steam 위시리스트 | Steamworks | 출시 전 7,000+ | 첫 주 판매량의 사실상 유일한 선행지표 |

## 7. 정리

- 이 게임의 수익화 문제는 **"어떻게 돈을 받을까"가 아니라 "무료 웹판의 마찰 없는 유입을 죽이지 않고 돈을 받을까"**다. 광고와 웹 IAP는 둘 다 그 강점을 깎아 먹으면서 회수는 못 한다.
