# AI 슬롭 진단 — 십이화 UI

`kill-ai-slop` 스킬(`yetone/kill-ai-slop`)로 스캔 후 전 항목을 직접 읽고 판정한 결과와,
그에 따라 실제로 고친 내역.

| | 진단 시점 | 현재 |
|---|---|---|
| 제품면 스캔 (`design/`·`docs/` 제외) | 14그룹 314건 | **10그룹 149건** |
| 가이드 페이지 단독 | 9그룹 26건 | **3그룹 4건** (전부 오탐) |
| `index.html` 이모지 | 205개 / 고유 72종 | **54개** |
| 고유 색상값 | 123종 / 423회 사용 | **102종 / 193회** |
| 본문 `<b>` | 240개 (한 문장 최대 7) | **161개** (최대 3, 전부 정당) |

---

## 한 줄 진단 (진단 시점)

**카드 48장은 그려진 그림인데, 그 위의 UI는 전부 이모지와 Tailwind 기본색이었다.**

`Assets/`에 월별 화투 아트 54장(webp)이 실려 있고 실제로 렌더되는데,
그 카드를 감싸는 모든 레이어 — 족보표 그림, 특수패 아이콘, 춘향 얼굴, 월 표시, 버튼 라벨 —
는 이모지로 채워져 있었다. 아트 디렉션이 한 화면 안에서 두 갈래로 갈렸다.

색도 같았다. `:root` 토큰이 11개뿐이라 중립색·등급색·상태색이 비어 있었고,
그 빈자리를 Tailwind 기본 팔레트 하드코딩 171회가 메우고 있었다.

가이드 페이지(`pages/guide/`)는 별개 문제였다 — **본편과 폰트·색·모양을 하나도 공유하지 않았다.**
Georgia 세리프 + 라운드 24px + 3열 카드 그리드 + `01 · / 02 ·` 번호 키커로,
게임 화면이 아니라 SaaS 랜딩 템플릿에 가까웠다.

## 고친 것

`deslop` 브랜치, 항목별 12커밋. 엔진(`==== ENGINE START/END ====`) 바깥만 건드렸고
`npm test`는 전 커밋에서 통과한다.

### 1. 가이드 섹션 키커 10개 삭제

`01 ·`~`08 ·` 번호 키커는 h2를 다시 말하거나 목차가 이미 알려주는 순서를 반복했고,
한국어 페이지의 `Official game guide`는 아무 정보도 주지 않았다. h2만 남기니 위계가 오히려 선명해졌다.

### 2. UI 라벨 이모지 제거 — 205 → 95

버튼·헤딩 접두 이모지(📖 📚 ✨ 🏷 🔥 🗑️ 🎯 🍶 🎴 🎉 🏆 🔄 ☠ ⚠ ▶ ☀️ 🌙)를
ko/en/ja 3개 로케일에서 걷어냈다.

- 설정·도움말 아이콘 버튼: ⚙ 📖 → 인라인 SVG(currentColor). 28px 모바일에서도 글자보다 낫다.
- 월 이모지: 상단 라벨·준비·주막에서 한자 월 표기로 충분 (`prepTitle`·`shopNextLabel`의 flower 인자 제거)
- ☀️🌙: `seasonline`이 이미 "낮 — 광·열끗 +2"라고 말하고 있었다
- 도움말 카드 제목의 20px 아이콘 타일(`.hc-title .ico`) 삭제 — 파스텔 아이콘 타일 그 자체였다
- 💰: 단위 '냥'과 중복 → 제거. 동전 파티클은 이모지 대신 CSS 금화로
- 설문 뱃지 🎴 → 같은 화면의 다른 뱃지와 동일한 아이콘 이미지

### 3. 중립색 124곳을 램프로 묶고 한지 톤으로

Tailwind slate 하드코딩 → `--ink-1`~`--ink-5` + `--ink-deep`.
**값을 그대로 둔 무손실 리팩터를 먼저 커밋하고, 그다음 토큰 6줄만 따뜻한 쪽으로 옮겼다.**
124곳을 한 번에 바꿨다면 되돌리기 어려웠을 diff가 6줄 수정이 됐다.

slate는 파란기가 도는 회색이라 초록 펠트와 금색 사이에서 차갑게 떴다.

### 4. 등급·족보 서열을 금색 단일 축으로

등급 색이 슬레이트/초록/분홍/호박 4색, 족보 티어가 금/빨강/호박/파랑/초록/회색 6색이었다.
**색을 여러 개 쓰면 순위가 아니라 카테고리로 읽힌다** — 초록이 분홍보다 높다는 근거가 없다.

- 커먼 → 레전더리: 흐린 한지선 → 금 2px + 글로우. 등급 칩은 마지막 단계만 금색 반전
- 족보 `t-s`~`t-d`: `--tier-*` 램프. 비삼광의 "삼광보다 한 톤 어둡게"라는 원래 의도는 금색 계열 안에서 유지
- 같은 아이디어를 6번 따로 정의하던 rgba 24줄을 `--rank-*`/`--tier-*` 토큰으로 통합
- 조커 발동 연출: 등급별 4색 → 금빛 하나 (발동 자체가 신호고, 등급은 테두리가 이미 말한다)

### 5. 족보표 그림을 카드 아트로

15행의 🕊️🏯🐦🌕☔🎀📜💥를 각 족보를 대표하는 카드 webp로 교체.
`Assets`에 48장이 이미 있는데 족보표만 이모지를 쓰고 있었다 — 추가 자산 비용 0.
대표 카드는 족보 조건이 지목하는 패로 골랐다(총통 = 11월, 비고도리 = 12월 제비, 피 5장 = 12월 쌍피).

### 6. 보이지 않는 블러 제거, 그림자 조이기

- 모바일 상단바 `backdrop-filter: blur(8px)`은 뒤 배경이 **96% 불투명**이라 아무것도 그리지 않으면서
  합성 레이어 비용만 냈다. 카드 태그의 `blur(2px)`도 26px 뱃지에서는 안 보인다. 둘 다 삭제.
  실제로 비쳐 보이는 설정 오버레이(.64)의 `blur(7px)`만 남겼다.
- 60~70px 블러 그림자 → 24~32px. 어두운 펠트 위에서 그건 그림자가 아니라 화면을 뿌옇게 만드는 것이다.
- `transition`에 걸려 있던 오버슈트 이징 5곳 → 표준 ease.
  정지 상태 사이의 전환은 되돌아오지 않는다. 특히 pip의 `width`/`margin` 오버슈트는 매 프레임 레이아웃을 유발했다.

### 7. 본문 강조 240 → 161

규칙을 하나 세웠다 — **`<b>`는 두 가지만 표시한다.**
(1) 화면의 버튼 이름(내기·버리기·고·스톱) (2) 런이 끝나는 조건(고박 = 런 종료).
숫자는 굵게 하지 않는다. 전용 숫자 폰트가 이미 눈에 띄고, 문장이 "내기 4회"라고 이미 말하고 있다.

### 8. 가이드를 본편과 같은 팔레트·글꼴·모양으로

- 제목 글꼴 Georgia → 본편의 `SSRock`. **Georgia에는 한글 글리프가 없어** 한국어 제목은
  `Nanum Myeongjo`로 넘어가는데 그 폰트를 로드하지 않아 결국 아무 스타일도 못 받고 있었다.
  h1·브랜드만 표시용 글꼴을 쓰고 h2·h3는 크기와 여백으로 위계를 만든다.
- 배경: 붉은/금색 radial 얼룩 2개 → 평면 펠트. 깊이는 실선으로.
- 섹션을 카드에서 빼냈다. 라운드 20px 상자 안에 또 라운드 14px 상자를 3열로 깔고 있어
  모든 내용이 같은 무게로 읽혔다 → 섹션은 실선 구분, 카드는 한 겹, 라운드는 본편과 같은 6px
- CTA 알약(999px) + 금색 그라디언트 → 본편과 같은 사각 금색 버튼
- 점수 공식의 등폭 글꼴 + 왼쪽 4px 바 제거 (공식은 코드가 아니다)

### 9. 팔레트 통합 — 고유 색 123 → 102, 사용 423 → 193

- 종이빛 흰색 7종(`#fffbeb` `#fff8e7` `#fffbef` …)은 서로 RGB 몇 단위 차이라 `--paper` 하나로.
  옅은 금 5종 → `--gold-pale`, 밝은 금 5종 → `--gold-lit`, 금틀 2종 → `--frame`
- 칩·배수 색을 Tailwind blue-400 / red-400에서 이 팔레트로. 역할은 그대로 두고 채도만 낮춰
  금색·펠트와 같이 놓이게 했다
- 코치 추천 뱃지: 라임 광택 구슬(`radial-gradient(circle at 40% 35%, …)`) → 평면 금색 원.
  카피의 "연두 빛"도 "금빛"으로 맞췄다 (ko/en/ja)
- 목표 초과 게이지의 금→분홍→라임 그라디언트 → 금색 한 축

### 10. 죽은 이모지 카드 폴백 제거 — 이모지 81 → 54

`MONTHS`의 `flower`/`yeolArt`/`gwangArt` 36개는 `card.art`가 없을 때만 쓰이는데
48장 전부 art가 있어 한 번도 타지 않는 경로였다. 폴백은 글자(光·월 이름·한자 월)로 바꿨다.

### 11. `scripts/rules.ko.mjs` — 스캐너 한국어 규칙

스킬이 러시아어 예제만 제공해서 한국어 카피는 자동 검출이 안 됐다.
이 프로젝트에서 실제로 나왔던 항목을 규칙으로 굳혔다.

```bash
node .agents/skills/kill-ai-slop/scripts/scan.mjs . --exclude=design --exclude=docs --rules=scripts/rules.ko.mjs
```

| id | 잡는 것 |
|----|---------|
| ko-01 | 한국어 AI 문투 — "단순한 X가 아니라 Y", 혁신적인/획기적인, "지금 바로 시작", "~을 통해 ~할 수 있습니다" 번역투 |
| ko-02 | 느낌표·물결표 남발 (한글 뒤 `!!`만 잡아 JS의 `!!`와 구분) |
| ko-03 | 강조 남발 — 한 줄에 `<b>` 4개 이상 |
| ko-04 | 번호 키커 — `01 ·` / `eyebrow` 클래스 |
| ko-05 | 한국어 화면의 영문 라벨 |

**함정**: 스캐너는 파일 전체를 한 덩어리로 매치하므로 줄 단위로 세려면 `[^\n]`을 써야 한다.
처음 `[\s\S]`로 썼다가 줄을 넘어가 오탐이 쏟아졌다.

| 개발용 프리뷰 패널 ▶ 4개 | `index.html:4445~` | 플레이어에게 안 보임 — 방치 |

**특수패**: 임시로 이모지를 지우고 **한자 1자 + 등급 테두리**만 써도 지금보다 낫다(광=光, 피=皮 식).
다만 22종에 한자를 배정하는 건 네이밍 결정이라 임의로 하지 않았다.

**춘향**: 몸통은 `<path>`/`<circle>`로 짠 벡터인데 얼굴만 이모지를 얹어,

**한 화면에 서로 다른 춘향이 둘 있는 것**이 진짜 문제일 수 있으니, 사이드 패널 아바타를
배경 춘향과 같은 그림으로 통일하는 방향을 먼저 검토할 것.

## 스캐너 오탐 (도구 한계 메모)

문자열 매칭이라 다음은 전부 오탐이다. 재실행 시 무시할 것.

- `17 left-border callout` → `-webkit-touch-callout: none`
- `15 emoji everywhere` → `©` 기호, `design/`·`docs/` 마크다운 표의 ✅
- `09 decorative strikes` → `text-decoration: underline` — 링크 밑줄은 이 스킬이 **권장하는** 형태
- `11 full-sentence display headline` → 음수 `letter-spacing`과 큰 `font-size`를 헤드라인으로 오인
- `24 AI-drawn SVG icon` → 춘향 SVG. 지적 자체는 맞지만 "아이콘"이 아니라 캐릭터다
- `34 tasteful-terminal` → `design/` 와이어프레임의 `var(--mono)`

## 유지 규칙

새 UI를 붙일 때 이 세 가지만 지키면 다시 슬롭으로 돌아가지 않는다.

1. **색은 `:root` 토큰에서만 가져온다.** 새 hex를 박기 전에 `--ink-*`/`--gold-*`/`--rank-*`/`--tier-*`에
   맞는 것이 없는지 먼저 본다. 없으면 토큰을 늘리고, 그 결정을 한 줄 주석으로 남긴다.
2. **서열은 색이 아니라 농도로.** 등급·티어·순위에 새 색상을 배정하지 않는다.
3. **장식은 뜻이 있어야 한다.** 이모지·굵기·아이콘·콜아웃은 신호일 때만 쓴다.
   `<b>`는 버튼 이름과 런 종료 조건에만.

스킬 설치물(`.agents/`·`.claude/`·`skills-lock.json`)은 프로젝트 의존성이 아니므로 gitignore 처리돼 있다.
설치: `npx skills add yetone/kill-ai-slop`
