기존 44.7초 마스터에서 **클라이맥스 4비트 + CTA만** 뽑아 이어붙였다. 재녹화도 재합성도 없다.
빌드: [`cut-hook.sh`](cut-hook.sh) — `./cut-hook.sh` (다른 비율은 `./cut-hook.sh 9x16`)

### 컷 구성 (6.00초)

| # | 마스터 TC | 길이 | 화면 | 역할 |
|---|---|---|---|---|
| 1 | 29.15 | 0.90s | 광 5장이 판에 내리꽂힌다 | **0프레임부터 사건.** 로고도 오프닝도 없다 |
| 2 | 30.80 | 0.85s | 「오광」 엠블럼 | 무슨 게임인지 1초 만에 확정 |

### 이 구성을 고른 이유

- **훅 3초 안에 다 넣었다.** 슬램 → 족보 → 조커 → 숫자가 2.5초 안에 끝난다. 유튜브 인피드는 처음 1초에 이탈이 결정된다.
- **44.7초 원본은 "가르친다 → 이유 → 엔진 → 터뜨린다" 구조**라 앞 20초가 교육 파트다. 광고에선 교육이 이탈 사유다. **결과부터 보여주고 이유는 게임 안에서 알게 한다.**
- **자막 없음(R10) 유지.** 음소거 시청이 기본이라 텍스트는 마지막 1.7초 CTA가 전부 짊어진다. 그래서 CTA에만 넉넉히 줬다.
- 0.25초마다 새 사건이 있다. 첫 렌더에는 33.9~34.15에 정지 구간 0.25초가 있었고 잘라냈다.

## 2. 영상 B — 아이디어 4안

### 전제: B는 A와 **다른 축**을 팔아야 한다

A는 **"한 방이 터진다"(밀도)** 를 팔았다. 같은 걸 길게 만든 건 B가 아니라 A의 변형이다.
A가 못 파는 것 세 가지 — ①이 게임이 **얼마나 긴가**(12판) ②**질 수 있다**는 긴장 ③**나도 할 수 있다**는 참여감.

---

### 안 1 · 「12판, 12초」 — 진행 몽타주 ⭐ 추천

**한 줄**: 1월부터 12월까지 한 달에 1초씩. 목표 숫자가 `160`에서 `5,500`으로 불어나고, 계절이 바뀌고, 3·6·9·12월엔 화면이 붉게 죽는다.

| 시간 | 화면 |
|---|---|
| 0.0–0.8 | `1월 · 송학` 목표 **160**. 고도리 한 방. 쉽다 |
| 0.8–4.0 | 2~5월. 컷당 0.6초. 계절 배경이 바뀌며 목표가 커진다 (`260` `420` `600` …) |
| 4.0–5.0 | **3월 박** — 화면이 붉게 물들고 `피박` 표식 |
| 5.0–11.0 | 6~11월. 컷이 점점 짧아지고(0.5→0.35s) 숫자·조커·이펙트가 빽빽해진다 |
| 11.0–14.0 | **12월 · 비**. 목표 **5,500**. 오광 폭발. 화면 전체가 금빛 |
| 14.0–16.0 | 금박 로고 + `몇 월까지 깰 수 있으세요?` |

- **파는 것**: 볼륨 + 난이도 곡선. "12판짜리 로그라이크"임을 유일하게 증명한다.
- **왜 추천하나**: A와 축이 정확히 갈리고, 카피 자산(`목표 160점에서 5,500점까지`, `1월부터 12월까지 12판`)과 이미지 #10(`ladder-12`)이 **같은 메시지로 묶인다.** 캠페인 전체가 한 목소리가 된다.
- **제작 비용**: 중간. 기존 녹화 리그로 월별 씬을 12개 찍어야 한다(`scenes.js`에 시드·월 지정). 생성 에셋 0개.
- **리스크**: 컷이 많아 편집 정밀도가 필요하다. 대충 만들면 "슬라이드쇼"로 읽힌다.

---

### 안 2 · 「고박」 — 실패를 보여주는 광고

**한 줄**: 점수가 폭주한다 → `고!` → 다음 판 실패 → **런 종료**. 마지막에 `욕심이 죽입니다.`

| 시간 | 화면 |
|---|---|
| 0–3 | 오광 폭발, `14,500 / 2,200`. A와 같은 쾌감 |
| 3–5 | `고!` 선언. 목표가 `2,200 → 3,520`으로 밀려 올라간다 |
| 5–8 | 다음 손패가 썩었다. 기회 4번이 하나씩 사라진다 |
| 8–10 | **고박 · 런 종료** — 화면 암전, 붉은 글자 |
| 10–12 | `욕심이 죽입니다.` + 로고 |

- **파는 것**: 리스크. 게임 광고에서 **실패 장면은 성공 장면보다 클릭률이 높은 경우가 많다** — "쉬워 보이는 게임"이 아니라 "이길 수 있을 것 같은 게임"으로 읽히기 때문이다.
- **왜 좋나**: 설명 #3(`고를 외치면 목표가 커집니다. 실패하면 고박, 런은 그대로 끝.`)과 정확히 맞물린다. 고스톱 아는 사람에게 "고박"은 **감정이 있는 단어**다.
- **제작 비용**: 낮음. 고박 씬 1개만 추가 녹화하면 나머지는 기존 A4 자산.
- **리스크**: "지는 게임"으로 오독될 여지. 마지막 카피가 도발로 읽히게 톤을 잡아야 한다. 그리고 **"욕심"·"고박"이 도박 뉘앙스로 심사에 걸릴 수 있다** — 영상 내 텍스트도 정책 검사 대상이다.

### 안 3 · 「몇 점일까요?」 — 참여형 퀴즈 훅

**한 줄**: 손패 8장을 2초 보여주고 정지. `여기서 몇 점 나올까요?` → 정답 공개, 오광 폭발.

| 시간 | 화면 |
|---|---|
| 0–0.5 | 손패 8장이 촥 펼쳐진다 |
| 0.5–3.0 | **정지**. 카드만 크게. 화면 위 `여기서 몇 점?` |
| 3.0–4.0 | 5장이 선택돼 내리꽂힌다 |
| 4.0–7.0 | 오광 → 조커 연쇄 → `14,500` |
| 7.0–9.0 | `맞히셨나요?` + 로고 |

- **파는 것**: 참여감. 시청자를 **플레이어로 만든다.** 2.5초 정지 구간이 시청 지속시간을 강제로 끌어올리고, 유튜브 인피드/Shorts에서 이건 그대로 도달로 환산된다.
- **왜 좋나**: 화투 족보를 아는 30~50대에게 **정확히 꽂히는 유일한 안**이다. 아는 척하고 싶게 만든다.
- **제작 비용**: 가장 낮음. 기존 A4 녹화 + 정지 프레임 + 텍스트 한 장.
- **리스크**: 정지 2.5초는 도박이다. 손패가 예쁘고 읽기 쉬워야 하고, 화투를 모르는 유저는 그 구간에서 이탈한다. → **B트랙(화투 오디언스) 전용**으로 돌려야 한다.

### 안 4 · 「춘향의 훈수」 — 캐릭터 IP

**한 줄**: 춘향이 카메라를 보고 말을 건다. "이거 낼 거예요? …진짜?" → 유저가 다른 패를 낸다 → 대박 → 춘향이 놀란다.

- **파는 것**: 캐릭터. 게임 안에 실제로 있는 조력자 시스템(3냥에 훈수 예약, 표정으로 알려줌)을 광고 소재로 꺼낸다.
- **왜 좋나**: 아트 자산(OG 춘향)이 이미 **캠페인에서 가장 강한 시각 자산**이다. 장기적으로 브랜드를 만든다.
- **제작 비용**: **가장 높음.** 춘향 애니메이션이 필요하고 Higgsfield 생성 파이프라인(H1/H2/H3)이 아직 미완이다. 게다가 대사가 들어가면 음소거 시청에서 자막이 필수가 되고, 이는 R10 방침과 충돌한다.
- **리스크**: 성적 암시 정책(→ [README §4-2](README.md))이 정지 이미지보다 영상에서 더 빡빡하다.

### 안 5 · 「1월 vs 12월」 — 8초 대비 ⭐⭐ 확정 (가장 간단)

**한 줄**: 쉬운 첫 판과 미친 마지막 판을 나란히 붙인다. **새로 찍는 게 하나도 없다.**

| 시간 | 마스터 TC | 화면 |
|---|---|---|
| 0.0–1.0 | 3.60 | 「고도리」 엠블럼 — 소박한 3장짜리 족보 |
| 1.0–2.4 | 9.20 | `180 / 160` — 겨우 넘겼다 |
| 2.4–3.4 | 30.80 | 「오광」 엠블럼 — 체급이 다르다 |
| 3.4–4.4 | 34.15 | 조커 5개 연쇄 |
| 4.4–6.3 | 35.20 | `5,000 → 14,500 / 2,200` |
| 6.3–8.0 | 41.70 | 금박 로고 + CTA |

- **파는 것**: 성장. 안 1(12판 몽타주)이 팔려던 볼륨 축을 **12개 씬 녹화 없이** 절반쯤 가져온다.
- **제작 비용**: **거의 0.** [`cut-hook.sh`](cut-hook.sh)의 `CUTS` 배열을 위 타임코드로 바꿔 한 번 더 돌리면 끝. 스크립트 복사본 하나 만들면 된다.
- **A와 겹치지 않나**: 뒷부분 소재는 겹치지만 **앞 2.4초가 전혀 다르다.** A는 "터진다" 한 축, B는 "여기서 시작해서 저기까지 간다"는 대비. 인피드에서 첫 1초가 다르면 다른 광고로 읽힌다.
- **한계**: 12판 전체를 보여주지는 못한다. 캠페인이 커지면 안 1을 제대로 만드는 게 맞다.
