## 1. 포지셔닝 — 이 게임이 파는 것

한 줄: **"고스톱을 아는 사람이 발라트로를 하면 이렇게 된다."**

두 개의 완전히 다른 오디언스가 있고, 하나의 소재로 둘 다 잡을 수 없다.

| | A · 덱빌더 게이머 | B · 화투 아는 한국인 |
|---|---|---|
| 나이 | 18~34 | 30~55 |
| 이미 아는 것 | 발라트로, 칩×배수, 조커 빌드 | 고도리·삼광·오광, 고/스톱, 박 |
| 모르는 것 | 화투 족보 | 로그라이크가 뭔지 |
| 훅 | "화투로 하는 발라트로" | "혼자 하는 고스톱인데 점수가 터진다" |
| 증명해야 할 것 | 빌드가 진짜 깊은가 (특수패 22종) | 룰이 익숙한가 (아는 족보 그대로) |
| 소재 | 조커 연쇄 발동 · 특수패 그리드 | 오광 슬램 · 춘향 · 족보표 |

**소재 10종은 이 두 트랙에 5:5로 배분한다.** 초반 2주 뒤 이긴 트랙에 예산을 몰아준다.

## 4. ⚠️ 정책 리스크 — 이거 안 보면 캠페인이 죽는다

### 4-1. 소셜 카지노 분류 위험 (심각도 높음)

구글은 "온라인 시뮬레이션 도박 스타일 게임"을 **소셜 카지노**로 분류하고, 광고하려면 **사전 인증**이 필요하다. 한국은 허용 국가에 들어있지만 **인증 없이는 게재 거부**된다.

화투로는 실제로는 소셜 카지노가 **아니다** — 상대 플레이어 없음, 현금 베팅 없음, 상금 없음, 순수 싱글 퍼즐/덱빌더다. 하지만 심사는 **크리에이티브를 보고 판단한다.** 화투패 + "내기" + "냥" + 고스톱이 한 화면에 있으면 걸린다.

**대응 (전부 적용할 것)**

| 조치 | 내용 |
|---|---|
| 카테고리 언어 고정 | 1순위 단어는 항상 **"로그라이크 덱빌딩"**. "고스톱"은 비유로만, 절대 단독 노출 금지 |
| 금지어 | 광고 문구에서 **내기 / 베팅 / 도박 / 판돈 / 잭팟 / 당첨 / 배팅** 전부 제외 |
| 게임 내 용어 치환 | 게임의 "내기 4회" → 광고에선 **"기회 4번"** |
| "냥" 표기 | 단독으로 쓰지 말고 "게임 재화"로 읽히게. 동전 무더기·돈다발 이미지 금지 |
| 랜딩페이지 고지 | `hwatro.jqklabs.com` 하단에 **"현금 베팅·상금이 없는 싱글 플레이 게임입니다"** 한 줄 추가 → 심사 반려 시 결정적 근거가 된다 |
| 반려 시 | 소셜 카지노 인증을 신청하지 말고 **먼저 이의 제기**하라. 인증을 받는 순간 카테고리가 고정돼 CPM이 뛴다 |

> 액션: 랜딩페이지 고지 문구 1줄 추가는 **광고 집행 전에** 넣어야 한다.

### 4-2. 성적 암시 콘텐츠 (심각도 중간)

`Assets/OG/OG*.png`의 춘향 히어로 아트는 가슴 노출이 상당하다. 구글 디스플레이/Demand Gen의 **성적 암시 콘텐츠** 정책에 걸릴 수 있고, 걸리지 않아도 **가족 지면(YouTube 상단 인벤토리)에서 배제**돼 도달이 깎인다.

**해결됨**: 광고 소재는 OG 아트를 쓰지 않는다. 춘향 **캐릭터 시트를 정본**으로 삼아 새로 생성했고, 프롬프트에 `OPAQUE inner garment, chest fully and modestly covered, no cleavage`를 고정으로 넣었다. 10종 전부 통과. OG 원본(카카오 링크 미리보기용)은 손대지 않았다. → [images.md](images.md)

### 4-3. 기타

- 저작권: 화투 도안은 공용 디자인이라 문제 없음. 폰트 라이선스는 `Assets/Fonts` 확인 필요(광고 이미지에 쓸 경우).
- "발라트로"는 **타사 상표** — 광고 문구·이미지에 직접 쓰지 말 것. "발라트로 같은"도 위험. 대신 **"로그라이크 덱빌딩"**으로 우회한다. (§copy.md에 반영됨)

## 5. 측정 — 이미 붙어 있는 걸 쓴다

Firebase GA4가 이미 연동돼 있다(`firebase-telemetry.mjs`). 새로 만들 필요 없다.

1. **GA4 ↔ Google Ads 연결** (GA4 관리 → Google Ads 링크)
2. GA4에서 아래를 **주요 이벤트(전환)** 로 표시 후 Ads로 가져온다

| 전환 | 정의 | 용도 |
|---|---|---|
| `hand_play` (첫 1회) | 패를 한 번이라도 냈다 | **입찰 최적화 기준** — 클릭이 아니라 실제 플레이 |
| `run_end` where `month >= 3` | 3월 벽까지 갔다 | 소재 품질 판정 |
| `session_play_sec ≥ 180` | 3분 이상 | 유입 품질 판정 |

3. 입찰: 초기 **클릭수 최대화**로 데이터 모으고, `hand_play` 전환 30건 이상 쌓이면 **전환수 최대화**로 전환.
4. UTM: 소재별로 `utm_content`를 반드시 다르게 → 어떤 이미지가 이겼는지 GA4에서 직접 본다.
