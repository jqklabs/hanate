```bash
./src/build-images-v3.sh     # 소재 12장 재생성
node src/charcount.mjs       # 문구 자수 검증
```

## 주의

- **소재의 타이포는 3단이다** — 로고 「십이화」 / 월별 부제 / CTA. 로고와 CTA는 붓글씨 이미지(12장 공용), 월별 부제만 인게임 폰트다. 공통 태그라인(「꽃으로 수놓은 밤」)을 넣어봤으나 블록이 세로로 길어져 뺐다 — 자산은 `gen/type/tagline/` 에 남아 있다.
- **인게임 폰트 `SSRockRegular` 는 서브셋이다** (한글 557자 / 완성형 11,172자). 부제 문구를 고치면 `src/lockup.py` 가 누락 글자를 stderr 로 경고한다. 무시하면 두부(⊠)가 그대로 나간다.
- **소재 하단 고지는 뺐다.** 「사행성 게임」은 물론 「재화」·「현금」도 그 자체가 도박 분류의 신호가 될 수 있어, 소재에는 아무 고지도 쓰지 않는다. 이 고지는 **랜딩페이지와 이의 제기 문서**가 담당한다 ([README §4-1](README.md)). 랜딩페이지 고지는 아직 미적용이다.
