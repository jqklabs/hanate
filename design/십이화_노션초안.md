## 1-3. 승자 카피 — 페이지 카피의 기준

**✅ 이기는 축**

| 유형 | 문장 | CTR |
| --- | --- | --- |
| 게임 규칙 명시 | 총 12판, 목표 점수는 치솟는다 | **8.61%** |
| 호기심 질문형 | 십이화, 그게 뭔데요? | **8.54%** |
| 장르 키워드 직격 | 1월부터 12월의 로그라이크 덱빌더 | 7.80% |
| 구체적 세계관 | 십이화, 단풍의 10월 | 7.37% |

**❌ 지는 축** (노출 0)

| 유형 | 문장 |
| --- | --- |
| 자기소개형 | 안녕하세요십이화입니다잘부탁드립니다 |
| 브랜드명 나열 | 십이화, 내가 키우는 나만의 덱 |
| 추상적 감성 | 48장이 만드는 수백 가지 조합 |
| 밈 · 은어 | 멈추면 쫄, 지르면 남자 |

**적용 규칙**

1. 상단 헤드라인은 **규칙 명시형 또는 호기심 질문형**으로 작성한다. 감성 문구로 시작하지 않는다
2. 섹션 제목에는 **구체적 숫자**를 넣는다 — 12판 · 48장 · 족보 13종 · 특수패 22종
3. 반(反)과금 메시지("뽑기도 광고도 없는")를 전면에 배치한다. 광고에서 CTR 6.5%를 냈고, 펀딩에서 더 강하게 작동한다

## 1-4. 미해결 과제 — 첫 화면 로딩

> 🔴 6.5초 이탈은 광고 종료로 해소되지 않는다.
> 펀딩 페이지에서 무료 데모로 유입된 사용자도 동일하게 이탈하며, **펀딩에서는 그것이 후원 포기로 직결된다.**

원인은 코드에 있다. `boot()`이 게임 화면 표시 전에 약 3.9MB를 전량 다운로드한다.

```
preloadCardImages()
  카드 아트 48종 + 오버레이 + 배경 2장
  ≈ 3.2MB (카드) + 0.67MB (배경 · BackgroundFigure.webp 단독 601KB)
  fetch → blob → decode, 6개씩 병렬
  ↓ 완료 후에야 첫 화면
```

모바일 LTE에서 2~4초, 저속 구간에서 10초 이상. **광고 유입 중앙 참여시간이 6.5초다.**

| 조치 | 시점 |
| --- | --- |
| `app_load_complete` 계측 추가 (소요 ms · 기기 · 네트워크) | 8월 4주차 |
| 로딩 완료 전 이탈률을 기기 · 네트워크별로 분리 | 9월 1주차 |
| **1월 카드 + 배경만 블로킹**, 나머지 11개월 지연 로드 | 9월 2주차 |
| `BackgroundFigure.webp` 압축 또는 지연 | 9월 2주차 |

**🎯 목표: 모바일 첫 화면 2.0초 이내.** 펀딩 오픈 게이트에 포함한다.

# 2. 크라우드펀딩 실행 계획

## 2-1. 구조 — 펀딩이 앞, Steam이 뒤

```
무료 웹판 (십이화)          ← 영구 무료 데모 · 유일한 유입구
      │
      ├─→ 펀딩 알림 신청  ─→ 텀블벅 + CAMPFIRE 동시 오픈 (1차 판매)
      │                              │
      │                              ↓ 화제성
      └─→ Steam 위시리스트 ─────────────→ Steam 정식 출시 (2차 · 롱테일)
```

| | 크라우드펀딩 | Steam |
| --- | --- | --- |
| 목적 | 수요 증명 · 화제성 · 선주문 | 장기 매출 |
| 시점 | 선행 | 후행 |
| 핵심 선행지표 | **알림 신청 수** | **위시리스트 수** |
| 최대 리스크 | **배송 지연** | 위시리스트 부족 |

## 2-2. 🇯🇵 일본 시장 — 화투는 하나후다다

> 일본은 단순한 해외 확장 대상이 아니라 **이 게임 소재의 원산지**다.

| 십이화 (한국) | 花札 (일본) |
| --- | --- |
| 고 / 스톱 | **こいこい(코이코이)** — "고"에 해당하는 선언이 이미 존재 |
| 오광 · 삼광 | 五光 · 三光 (동일) |
| 고도리 | **五鳥(ごとり)** — 고도리는 일본어 어원 |
| 홍단 · 청단 | 赤短 · 青短 (동일) |
| 띠 · 열끗 · 피 | 短冊 · タネ · カス (동일 체계) |

**세 가지 결과**

1. **일본어 로컬라이제이션이 영어보다 쉽다.** 족보 용어는 번역이 아니라 **원어 복원**이다. [수익화-방안](../docs/수익화-방안.md)이 지목한 "족보 용어 번역 난제"는 일본 시장에 존재하지 않는다
2. **설명 비용이 낮다.** 하나후다를 아는 사용자에게 "이것을 로그라이크로 만들었다"는 3초면 전달된다
3. **실물 카드 시장이 살아 있다.** 닌텐도가 현재도 하나후다를 판매한다 — 동시에 **품질 기대치도 높다**

**대응 사항**

- 일본에서 花札는 **賭博 이미지**를 동반한다. 페이지 톤을 문화·게임으로 고정하고, "현금 베팅·상금 없는 싱글 플레이" 고지를 **일본 페이지에도 게재**한다
- **일본어 CS · 배송 대응 인력을 오픈 전에 확보한다.** 동시 오픈의 필수 전제다
- CAMPFIRE 해외 창작자 등록 요건을 8월 4주차에 확인한다 → **C2**

## 2-3. 동시 오픈 — 결정과 그 대가

> **텀블벅과 CAMPFIRE를 동시에 오픈한다.**

**✅ 유리해지는 것**

- **제조** — 양국 물량을 1회 생산으로 처리한다. 단가가 낮아지고 재고 보유 기간이 짧다
- **화제성** — 양국 실적이 합산 노출된다. "한·일 동시 펀딩"은 그 자체가 보도 소재다

**⚠️ 감당해야 하는 것**

- **운영 부담** — 번역 · CS · 배송을 동시에 감당한다. 일본어 대응 인력이 오픈 전에 확보돼야 한다
- **일정** — 두 플랫폼의 심사 일정이 다르다. 오픈일을 역산해 심사 제출일을 각각 정렬한다
- **리스크 전이** — 한쪽에서 발생한 배송 사고가 양국 평판에 동시 반영된다

**필수 준비**

- [ ] 일본어 페이지 번역 (게임 소개 · 리워드 · FAQ · 배송 안내)
- [ ] 일본어 CS 대응 체계
- [ ] 일본 배송 방식 · 비용 확정 (개별 국제배송 vs 현지 대행)
- [ ] 양국 목표액 각각 산정
- [ ] 두 플랫폼 심사 제출일 정렬

목표액은 **약속을 이행할 수 있는 최소치**로 설정한다. 목표 미달 시 전액 환불되므로, 낮게 설정하고 초과 달성하는 편이 플랫폼 노출과 화제성 양쪽에 유리하다.

```
목표액 = 굿즈 제조 원가 + 배송 + 플랫폼·PG 수수료 + 예비비(20%)

※ 개발비는 산입하지 않는다 — 이미 완성된 게임이다
```

## 2-5. 채택하지 않는 수익 모델

**❌ 인게임 리워드 광고**
삽입 지점(고박 부활 · 리롤 · 훈수)이 전부 긴장 설계의 핵심이다. 고박이 런 종료이기에 고가 위험하고, 리롤이 유한하기에 상점이 선택이 된다. 광고로 되돌리는 순간 밸런스 철학이 붕괴한다. 추가로 화투 + 광고 조합은 소셜 카지노 심사 트리거다.

**❌ 웹 IAP**
계정 · 서버 · 환불 인프라 공수가 게임 개발 공수를 초과한다. 무로그인이라는 최대 강점을 스스로 제거한다.

**❌ 모바일 스토어 선출시**
카지노 카테고리 심사 대상이며 GRAC 등급분류가 선행된다. Steam 이후로 미룬다.

**❌ itch.io · 후원 버튼**
펀딩과 메시지가 중복된다. 펀딩 종료 후 재검토한다.

**❌ 유료 광고 재개**
유저당 매출 ₩0. 구조적으로 회수 불가능하다.

> 🚫 **레드라인**
> 인게임 재화 "냥"의 현금 구매 · 환전은 어떤 형태로도 도입하지 않는다.

> **후원의 이유는 게임이다.**
> 굿즈는 게임을 구매하는 사용자에게 부가되는 것이며, 굿즈를 목적으로 유입시키지 않는다.

**실물 SKU는 3종으로 확정한다.**

- **지연 리스크 = 평판 리스크** — 크라우드펀딩 최대 사고는 실패가 아니라 배송 지연이다. SKU 3개는 사고 지점 3개를 의미한다
- **제조 관리가 개발 시간을 잠식한다** — 견적 · 샘플 · 검수 · 포장 · CS가 SKU마다 발생한다. 현 시점의 우선순위는 저장 시스템 구현이다
- **메시지 희석 방지** — 굿즈가 많으면 "굿즈 펀딩"으로 인식된다. 판매 대상은 12판을 버티는 게임이다
- **모수 부족** — 특수패 · 족보표는 게임을 아는 사용자에게만 의미가 있다. 현재 그 모수가 존재하지 않는다

> 💡 이 방향은 실측과 일치한다.
> 광고 CTR 1위 문장이 **"총 12판, 목표 점수는 치솟는다"(8.61%)** — 게임 규칙 명시형이었다.

> **북극성 지표는 하나 — 펀딩 목표액 달성.**
> 나머지 모든 수치는 그 질문에 답할 때만 KPI로 취급한다.

현 단계에서 필요한 것은 목표치가 아니라 **기준선**이다. 이 프로젝트에는 자체 벤치마크가 없으며, 유일한 데이터인 광고 5일치는 오염돼 있다.

| --- | --- | --- |

## 5-2. 결과 KPI — 목표액 역산

```
필요 후원자   = 목표액 ÷ 평균 후원액
필요 알림 신청 = 필요 후원자 ÷ 알림→후원 전환율
```

굿즈를 3종으로 축소했으므로 평균 후원액이 낮아진다. **이것이 축소 결정의 대가다.**

| | 굿즈 다품목 (폐기안) | **게임 중심 (확정안)** |
| --- | --- | --- |
| 실물 SKU | 8종 이상 | **3종** |
| 게임 단품 티어 | ₩9,900~14,000 | **₩7,900~10,900** |
| 가정 평균 후원액 | ₩40,000 | **₩22,000** |
| 제조 · 지연 리스크 | 높음 | **낮음** |
| 동일 목표액 대비 필요 후원자 | 기준 | **약 1.8배** |

**역산 결과** — 평균 후원 ₩22,000 · 알림→후원 전환 15% 가정

| 시장 | 목표액 | 필요 후원자 | 필요 알림 신청 |
| --- | --- | --- | --- |
| 🇰🇷 텀블벅 | ₩2,000,000 | 약 91명 | **약 610** |
| 🇯🇵 CAMPFIRE | 한국의 절반 | 약 46명 | **약 300** |
| **합계** | — | **약 137명** | **약 910** |

> 현재 Firebase 30일 활성 사용자는 **367명**(8/11)이다.
> **필요 알림 910건은 커뮤니티 시딩이 성과를 내야 도달 가능한 수치이며, 시딩은 선택이 아니라 필수 과업이다.**

평균 후원액이 ₩25,000에서 ₩22,000으로 내려간 것은 게임 단품 티어를 Steam 정가 아래로 재배치한 결과다. **정가 정합성을 확보한 대가로 필요 후원자가 늘었다.** 평균 후원액 · 전환율은 업계 통념 기반 추정치이며 C1 · C3 확정 후 재산정한다.

# 6. 로드맵

## 6-1. 8월 4주차 (8/24~) — 착수

```
광고    캠페인 정지 · 최종 리포트 확보 · 계정 유지
브랜드  "십이화" 전 문서·코드 일괄 반영
굿즈    화투덱 제조사 3곳 견적 · 카드 샘플 발주   ← 리드타임 최장, 최우선
확인    CAMPFIRE 해외 창작자 등록 요건 (C2)      ← 일정 전체를 흔들 수 있음
적립    Steam 페이지 선공개 · 텀블벅 알림 페이지 개설
계측    app_load_complete 이벤트 추가
```

## 6-2. 9월 — 자격 확보

```
개발    저장/불러오기 구현        ← 두 축 공통 하드 블로커
        첫 화면 로딩 2초 달성
        폰트 라이선스 실사 (C4)
굿즈    카드 샘플 수령·검수 · 목표액 산출 (C1·C3)
일본    페이지 번역 · CS 체계 · 배송 방식 확정
적립    커뮤니티 시딩 (한국 + 일본) · 알림 4주 측정
        → 측정 기울기로 목표액 최종 확정
콘텐츠  펀딩 페이지 초안 (광고 자산 재활용)
```

## 6-3. 10월 이후 — 판매

```
게이트 A·B·C 전수 통과 확인
      ↓
텀블벅 + CAMPFIRE 동시 오픈
      ↓
굿즈 제조·배송 (1회 생산, 양국 동시)
      ↓
Steam 정식 출시
```

## 6-4. 요약

1. 광고는 실패가 아니라 **재료를 남겼다.** 영상 · 이미지 · 검증된 문장이 펀딩 페이지의 뼈대다.
2. 두 축의 하드 블로커가 **저장 시스템으로 수렴한다.** 개발 우선순위는 이것으로 확정된다.
3. 현 시점에 만들 것은 매출이 아니라 **오픈일에 전환될 사전 수요**다.
