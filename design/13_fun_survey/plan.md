# 화투로 — 재미(Fun) 피드백 설문 설계

> 모드: `FEATURE` (게임 시스템 아님 — 유저 리서치 산출물)
> 무게감: **Tier B** — 게임 루프 외부. 단, 결과가 밸런스·조커·박 라운드 확정치를 흔들 수 있어
> "설계 근거 + 분석 계획"까지는 문서화한다. 문항 문구는 그대로 폼에 복붙 가능한 상태.

## 0. 이 설문이 답해야 하는 질문 (측정 목표)

문항은 "궁금한 것"이 아니라 **"결과에 따라 무엇을 바꿀지 정해진 것"**만 넣는다.
아래 5개 외의 질문은 전부 잘라냈다.

| # | 의사결정 질문 | 결과가 바꾸는 것 | 담당 문항 |
|---|---|---|---|
| D1 | 난이도 커브(160→5,500)가 "빡빡함"인가 "불공정함"인가 | 목표 커브 · 3월/6~7월 벽 | Q6–Q9 |
| D2 | 고/스톱 무제한 밀치기가 실제로 짜릿한가, 아니면 안 쓰나 | 고 보너스 n×m냥, 문턱 계수 0.6 | Q10–Q12 |
| D3 | 조커 22종 중 무엇이 재미의 축인가 (배수 빌드가 유일해인가) | 조커 리밸런스 우선순위 | Q13–Q15 |
| D4 | 점수 규칙(족보 기본칩 없음 · core만 배수)이 이해되는가 | 온보딩/도움말, 프리뷰 UI | Q4–Q5 |
| D5 | 왜 이탈했는가 (어려움 / 불명확함 / 반복 / 분량) | 다음 스프린트 최우선 항목 | Q16–Q18 |

**측정하지 않기로 한 것**: 아트 선호, 사운드(미구현), NPS(표본 크기 부족), 과금 의사(비상업).

## 1. 설문 구조와 분량

원칙: **3분 이내 · 필수 12문항 · 서술 2문항.** 프로토타입 설문은 길면 이탈자가
답을 안 남기고, 이탈자가 가장 중요한 응답자다.

| 섹션 | 문항 | 목적 | 소요 |
|---|---|---|---|
| S0 스크리너 | Q1–Q3 | 플레이 실적으로 응답 가중 | 20s |
| S1 이해도 | Q4–Q5 | D4 — 재미 이전의 전제 | 25s |
| S2 난이도 | Q6–Q9 | D1 | 40s |
| S3 고/스톱 | Q10–Q12 | D2 | 30s |
| S4 조커·빌드 | Q13–Q15 | D3 | 35s |
| S5 이탈·자유 | Q16–Q19 | D5 | 40s |

분기: Q2 = "1판(1월)도 못 깼다" → S3·S4 **스킵** (고를 못 해본 사람의 고 평가는 노이즈).

## 2. 문항 (그대로 복붙)

척도는 전부 **5점**으로 통일한다. 7점은 프로토타입 표본에서 해상도만 늘고 신뢰도는 안 오른다.
동의 척도 라벨 고정: `1 전혀 아니다 / 2 아니다 / 3 보통 / 4 그렇다 / 5 매우 그렇다`

### S0. 먼저, 어디까지 해보셨나요

**Q1. 화투로를 총 몇 번 플레이했나요? (한 번 = 시작부터 죽거나 그만둘 때까지)** `단일선택`
- 1번 / 2–3번 / 4–9번 / 10번 이상

**Q2. 가장 멀리 간 판은 몇 월인가요?** `단일선택`
- 1월도 못 깼다 / 2–3월 / 4–6월 / 7–9월 / 10–11월 / 12월 클리어

> 근거: 시뮬레이션상 무조커 봇은 3월(~14%)에서, 상점 봇은 6~7월에서 죽는다.
> 구간을 이 두 벽 앞뒤로 끊어야 "봇보다 잘하는 사람"이 분리된다.

**Q3. 고스톱(실제 화투 게임) 규칙을 알고 있었나요?** `단일선택`
- 잘 안다 / 대충 안다 / 이름만 들어봤다 / 전혀 모른다

> 근거: 족보·박·고를 아는 사람과 모르는 사람의 이해도 점수는 반드시 갈린다.
> Q4–Q5를 이 값으로 층화하지 않으면 "설명이 부족한지"를 판정할 수 없다.

### S1. 규칙이 이해됐나요

**Q4. 다음을 얼마나 이해했나요?** `매트릭스 · 5점(1 전혀 모르겠다 ~ 5 완전히 이해)`

| 항목 |
|---|
| 낸 카드의 점수가 어떻게 계산되는지 |
| 족보에 들어간 카드만 배수를 받는다는 점 |
| 이달의 패(×2), 밤일낮장(+2칩) |
| 고를 선언하면 목표가 어떻게 올라가는지 |
| 박 라운드(피박·광박 등)가 무엇을 막는지 |

**Q5. 점수 계산을 이해한 계기는 무엇인가요?** `단일선택`
- 카드를 고르면 나오는 점수 프리뷰 / 도움말 화면 / 여러 번 죽으면서 감으로 / 원래 고스톱을 알아서 / 아직도 잘 모른다

> D4 판정: "프리뷰"가 1위면 온보딩은 지금대로 두고 프리뷰를 강화한다.
> "감으로"·"아직도 모른다"의 합이 40% 넘으면 온보딩을 만든다.

### S2. 난이도

**Q6. 전체적인 난이도는 어땠나요?** `단일선택`
- 너무 쉽다 / 조금 쉽다 / 딱 좋다 / 조금 어렵다 / 너무 어렵다

**Q7. 가장 크게 막혔던 판은 몇 월인가요?** `단일선택` (1월 ~ 12월 / 막힌 느낌 없었다)

**Q8. 그 판에서 죽었을 때 어떤 느낌이 가장 가까웠나요?** `단일선택` ★핵심
- **A. 내가 잘못 골랐다 — 다시 하면 될 것 같다**
- **B. 조커/상점 운이 나빴다 — 뽑기가 문제다**
- **C. 뭘 해도 점수가 안 나오는 구조 같았다**
- **D. 뭐가 문제였는지 모르겠다**

> ★ D1을 갈라내는 단 하나의 문항. **A = 빡빡함(좋음, 유지)**, B = 상점 분산 문제,
> **C = 불공정함(목표 커브 하향 검토)**, D = 피드백/가독성 문제.
> CLAUDE.md의 "하향보다 상향 우선" 정책은 **C가 과반일 때만** 예외로 재검토한다.

**Q9. 죽은 직후 바로 다시 시작했나요?** `단일선택`
- 항상 바로 다시 했다 / 대체로 다시 했다 / 반반 / 대체로 그만뒀다 / 한 번 죽고 안 했다

> "한 판 더"의 행동 지표. Q6의 주관 난이도보다 이 값이 실제 재미에 더 붙는다.

### S3. 고/스톱 (Q2 = "1월도 못 깼다"면 스킵)

**Q10. 목표 점수를 넘겼을 때, 고를 얼마나 선언했나요?** `단일선택`
- 거의 항상 고 / 자주 고 / 반반 / 대체로 스톱 / 거의 항상 스톱

**Q11. 고를 선언하는 순간이 짜릿했나요?** `5점 동의`

**Q12. 고를 안 하게 되는 이유가 있었다면 무엇인가요?** `복수선택 · 최대 2개`
- 실패하면 런이 끝나서(고박) 무섭다
- 보너스(n×m냥)가 위험에 비해 적다
- 다음 목표가 얼마인지 계산이 안 된다
- 손패가 이미 소진돼서 물리적으로 불가능했다
- 특별히 없다 — 잘 하고 있었다

> D2 판정: "무섭다"가 1위면 고박 페널티가 아니라 **보너스를 올린다**(고 선언 자체는 무제한 유지 —
> 확정 사항). "계산이 안 된다"가 1위면 밸런스가 아니라 **다음 문턱 표기 UI** 문제.

### S4. 조커와 빌드

**Q13. 한 판에서 특히 강했다고 느낀 특수패를 최대 3개 골라주세요.** `복수선택 · 최대 3개`
- (커먼) 광팔이 / 피장사 / 멍따 / 쪽집게 / 쌍피보따리 / 띠장수
- (레어) 싹쓸이 / 고도리꾼 / 단골 / 흔들기 / 광모이 / 피오장 / 초단꾼
- (에픽) 비광우산 / 폭탄 / 밑장빼기 / 피박보험 / 멍잔치 / 삼광판
- (레전더리) 열두사철 / 오광소원 / 명인
- 딱히 없었다 / 이름을 기억 못 한다

**Q14. 반대로, 사놓고 "이건 별로였다" 싶은 특수패가 있었나요?** `복수선택 · 최대 3개` (동일 목록 + "없다")

> Q13∩Q14 교집합이 큰 조커 = 상황 의존이 심한 것. 교집합이 작고 Q14만 큰 것 = 순수 하향 후보.
> **Tier별 응답 밀도도 본다** — 레전더리 3종이 Q13 상위에 없으면 티어 가격/효과가 약하다.

**Q15. 판마다 다른 전략을 시도하게 됐나요, 아니면 같은 방식이 정답처럼 느껴졌나요?** `단일선택`
- 매번 다른 빌드를 시도했다 / 대체로 다르지만 뼈대는 같았다 / 거의 항상 같은 방식이었다 / 전략이라고 할 만한 게 없었다

> D3 판정: "거의 항상 같은 방식" + Q13이 삼광판/광 계열로 쏠리면 **배수 빌드 독점**이 확인된다.
> 그때 대응은 광 하향이 아니라 **다른 축(피·띠·단 계열) 상향** — 상향 우선 정책 유지.

### S5. 이탈과 자유 의견

**Q16. 그만두게 된 가장 큰 이유는 무엇인가요?** `단일선택`
- 아직 하고 있다 / 너무 어려워서 / 뭘 해야 할지 모르겠어서 / 반복이 지루해서 /
  한 판이 너무 길어서 / 버그·불편함 / 그냥 시간이 없어서

**Q17. 한 판(1월→12월)의 길이는 어땠나요?** `단일선택`
- 너무 짧다 / 조금 짧다 / 딱 좋다 / 조금 길다 / 너무 길다

**Q18. 이 게임에서 가장 재미있었던 순간을 한 문장으로 적어주세요.** `단문 · 필수`

> ★ 정량 문항이 못 찾는 것을 찾는 문항. **필수로 두는 이유**: 여기 모인 문장이
> 다음 기획의 "지켜야 할 것" 목록이 된다. 응답이 전부 특정 시스템(예: 고 밀치기)을
> 가리키면 그 시스템은 건드리지 않는다.

**Q19. 딱 하나만 바꿀 수 있다면 무엇을 바꾸고 싶나요?** `단문 · 선택`

## 3. 문항 설계 규칙 (왜 이렇게 썼는지)

| 규칙 | 이유 |
|---|---|
| "재미있었나요?"를 직접 묻지 않는다 | 예/아니오 이상의 정보가 안 나온다. 재미는 Q8(귀인) · Q9(재시작) · Q18(순간)으로 **삼각측량**한다 |
| 유도 문구 금지 | "짜릿한 고 시스템이 마음에 들었나요?"(✗) → "고를 선언하는 순간이 짜릿했나요?"(Q11, 5점) |
| 한 문항에 한 개념 | "난이도와 분량은 어땠나요?"(✗) → Q6 / Q17 분리 |
| 내부 용어를 유저 용어로 | "core 카드"(✗) → "족보에 들어간 카드"(Q4) |
| 복수선택엔 상한 | Q13/Q14 최대 3개 — 상한 없으면 전부 체크해서 순위가 사라진다 |
| 부정 문항도 반드시 | Q14, Q16 없으면 긍정 편향된 결과만 남는다 |
| "모르겠다" 선택지 제공 | Q8-D. 억지 선택은 데이터를 오염시킨다 |

## 4. 분석 계획 (수집 전에 확정 — 사후 해석 방지)

**층화**: 모든 결과는 Q2(도달 월) × Q3(고스톱 경험)으로 쪼개서 본다.
합산 평균은 실력·배경이 섞여 의미가 없다.

**판정 규칙** — 아래 임계값은 [가정]이며, "표본을 보고 정하기"를 막기 위한 사전 선언이다.

| 조건 | 결론 | 액션 |
|---|---|---|
| Q8 = C가 40%↑ | 커브가 불공정 | 목표 커브 재검토 (상향 우선 정책의 유일한 예외) |
| Q8 = A가 50%↑ | 의도대로 빡빡함 | 난이도 유지 |
| Q8 = D가 30%↑ | 피드백 부족 | 정산 화면에 "왜 모자랐는지" 표기 |
| Q4 특정 행 평균 ≤ 3.0 | 그 규칙 전달 실패 | 해당 항목 온보딩/툴팁 |
| Q9 하위 2개 합 50%↑ | 재시작 훅 부재 | 런 종료 화면 개선 |
| Q15 = "거의 항상 같은" 40%↑ | 빌드 다양성 실패 | 비주류 축 상향 |
| Q12 = "무섭다" 1위 | 고 리스크/보상 불균형 | 보너스 계수 상향 검토 |

**표본 목표**: [가정] 유효 응답 **30명 이상**(층화 셀당 최소 5). 그 미만이면 정량 판정을
보류하고 Q18·Q19 서술만 정성 분석한다 — 이것도 사전에 정해둔다.

**Analytics와의 교차 검증**: 설문은 자기보고라 틀린다. 반드시 대조한다.

| 설문 | 대조 이벤트 (docs/analytics.md) |
|---|---|
| Q2 도달 월 | `run_end.month` 분포 |
| Q10 고 빈도 | `run_end.go_count` |
| Q13 강한 조커 | `shop_buy.joker_id` × 생존율 |
| Q17 한 판 길이 | `run_end.duration_sec` |

**설문 ↔ 로그 결합**: 첫 문항 앞에 `hwatro_uid` 붙여넣기 칸을 **선택**으로 둘 수 있으나,
프로토타입 표본에서는 붙여넣기 마찰이 이탈을 늘린다 → **[확인필요] 넣을지 결정 필요.**
기본안은 "넣지 않고 집계 수준에서만 대조".

## 6. 남은 결정 사항
