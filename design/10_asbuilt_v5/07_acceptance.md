# 완료 기준

**대상**: 현행 구현(v5) · Tier S → 15개 이상 요구, **57개** 작성
**성격**: REVISE 모드이므로 두 종류다 — ✅는 **현재 구현이 이미 만족**(회귀 테스트 항목), ☐는 **아직 미달**(작업 목록).

각 항목은 관찰 가능한 문장이며, 그대로 테스트 하나가 된다.

## A. 기능 — 스코어링 (Tier S 핵심)

- [x] **A1** 손패 8장에서 1~5장을 선택하고 내기를 누르면 `(코어 카드칩 × 배수 + flat)`이 판 점수에 가산된다
- [x] **A2** 프리뷰 패널의 예상 점수와 실제 획득 점수가 항상 일치한다 (프리뷰는 `computeScore` 드라이런)
- [x] **A3** 12월 오광을 명인·오광소원·비광우산·광모이와 함께 내면 정확히 **8,690점**이 나온다 (`04_balance §7-2` 손검산)
- [x] **A4** 열끗 5장을 내면 칩 높은 3장만 배수를 타고 나머지 2장은 flat으로 들어간다 (POL-SCR-04)
- [x] **A5** 흔들기(×1.5)가 걸려도 최종 점수에 소수점이 남지 않는다 — `Math.floor`가 마지막 1회만 적용된다
- [x] **A6** 3월(홀수·낮)에 3월 광을 내면 칩이 `12 × 2 + 2 = 26`이다 (이달의 패 → 밤낮 순서)
- [ ] **A7** 코드 주석 `index.html:2946`의 "+3칩"이 실제 값 **+2**로 수정되어 있다 *(드리프트 #2)*

## B. 기능 — 고 / 스톱

- [x] **B1** 목표를 넘긴 순간 손패를 보충하지 않고 고/스톱 모달이 뜬다 (`pendingGoStop`)
- [x] **B2** 고를 선언하면 새 목표가 **항상 현재 점수보다 크다** — 어떤 점수에서도 공짜 연쇄 고가 나오지 않는다
- [x] **B3** 1월에서 450점을 만들고 고를 선언하면 3고(448 문턱)까지 밀린 뒤 4고(544)가 새 목표가 된다
- [x] **B4** 3단계를 한 번에 밀쳐도 내기는 **1회만** 늘어난다 (POL-GO-03)
- [x] **B5** 내기가 0회 남았어도 고를 선택할 수 있고, 선택하면 내기 1회로 계속할 수 있다
- [x] **B6** 덱과 손패가 모두 소진된 상태로 목표를 넘기면 고/스톱 없이 곧바로 정산으로 간다
- [x] **B7** 고 선언 후 목표에 못 미치고 내기가 떨어지면 런 종료 사유가 "고박"으로 표시된다
- [x] **B8** 고 버튼 연출이 2~3고는 하이퍼번, 4고 이상은 옆 밀치기로 재생되고, 모달이 연속 렌더돼도 연출이 중복되지 않는다

## C. 기능 — 경제 · 상점

- [x] **C1** 정산 내역의 이자가 **가산 전 보유금** 기준으로 계산되고 5냥을 넘지 않는다
- [x] **C2** 3·6·9·12월 정산의 기본 상금이 6냥이다 (그 외 4냥)
- [x] **C3** 상점 오퍼 3장에 이미 보유한 특수패가 나오지 않고, 서로 중복되지 않는다
- [x] **C4** 리롤 비용이 2냥에서 시작해 누를 때마다 1냥씩 오르고, 다음 상점에서 2냥으로 리셋된다
- [x] **C5** 밑장빼기를 팔면 누적 점수가 0으로 리셋된다
- [x] **C6** 광팔이 보유 시 광을 내면 냥이 오르되 **한 판에 3냥까지만** 오른다
- [ ] **C7** 슬롯 5칸이 가득 찬 상태에서 전 구매 버튼이 회색이 될 때, **그 이유가 화면에 표시**된다 *(EXC-01)*

## D. 기능 — 박 라운드

- [x] **D1** 3월 박은 피박·광박·멍박 중에서만 나온다
- [x] **D2** 같은 박이 한 런에서 두 번 나오지 않는다
- [x] **D3** 12월 진입 전 상점에서 박 후보 2종 중 하나를 고르기 전까지 `[다음 판으로]`가 잠긴다
- [x] **D4** 피박보험을 들고 있으면 피박·광박·멍박 판에서 칩이 0이 되지 않고, 라운드 패널에 "→ 무효!"가 표시된다
- [x] **D5** 안개 판에서 뒷면 카드를 포함해 선택하면 프리뷰가 "미리보기 불가"로 바뀌고, 내는 순간 공개된다
- [x] **D6** 안개 판에서 한 번 공개된 카드는 다시 뒷면이 되지 않는다 (POL-BOS-01)
- [x] **D7** 비바람 판에서 버리기 버튼이 `(0회 남음)`으로 비활성이고, 박 배너가 그 이유를 설명한다
