# Higgsfield 삽입 슬롯

편집본에 **자리표시자로 이미 들어가 있다.** 파일을 넣으면 그 자리에 자동으로 교체된다.

## 넣는 법

```
design/14_campaign_video/capture/plates/H1.mp4   ← 여기에 두면 끝
```

- 확장자: `.mp4` `.mov` `.webm` (정지컷이면 `.png` `.jpg`도 가능)
- 파일이 없으면 **슬롯 이름과 길이가 적힌 자리표시자**가 렌더된다 → 편집본에서 위치·박자를 눈으로 확인할 수 있다
- 규격: **1080×1350 (4:5)** 권장. 다른 비율로 와도 중앙 크롭으로 맞춘다
- 재생성 없이 `node capture/assemble.mjs --ratio 4x5` 만 다시 돌리면 반영된다

## 슬롯별 프롬프트 방향

공통 톤: 짙은 녹색 배경, 금박, 홍단 레드. 실사가 아니라 **채색 일러스트/애니메이션**.
캐릭터는 `char/춘향_누끼.png` 기준 — 땋은 머리, 흰 저고리에 붉은 고름, 진홍 치마.

**H1 — 훅 (1.8s)**
> 춘향이 화투패 다섯 장을 부채처럼 펴들어 얼굴 아래를 가린 채 카메라를 응시한다.
> 패 너머로 눈만 보이다가 패를 살짝 내리며 미소. 카메라는 아주 천천히 밀고 들어간다.
> 배경은 짙은 녹색 판, 금빛 입자가 느리게 떠다닌다.

**H2 — 브릿지 (1.2s)**
> 낡은 나무 탁자 위 부적(특수패)에 불꽃이 옮겨붙어 금빛으로 타오른다.
> 종이 가장자리가 붉게 달아오르고 불티가 위로 솟는다. 클로즈업, 얕은 심도.

**H3 — 리액션 (1.4s)**
> 춘향이 눈을 크게 뜨고 상체를 뒤로 젖힌다. 금빛 섬광이 얼굴을 때리고
> 머리카락과 옷자락이 뒤로 날린다. 놀람에서 만족스러운 웃음으로 바뀐다.

## 확인 방법

```
node design/14_campaign_video/capture/assemble.mjs --ratio 4x5
```

콘솔에 아직 안 채운 슬롯이 뜬다:

```
⚠ H1: plates/H1.* 없음 → 자리표시자 (오프닝 — 춘향이 패를 부채처럼 펴들고 정면 응시)
⚠ H2: plates/H2.* 없음 → 자리표시자 (브릿지 — 특수패(부적)에 불이 붙는 클로즈업)
⚠ H3: plates/H3.* 없음 → 자리표시자 (절정 직후 — 오광에 놀란 춘향 리액션)
```

영상에서도 해당 구간에 `[ H1 ]` `1.8s` 가 적힌 화면이 나오므로 박자를 미리 볼 수 있다.
